# S6 전경 장식 원화

2026-10-02 게임 화면에서 기존 꽃·풀의 색이 탁하고 배경과 분리되어 보인다는 요청에 따라, 초기 S6 장식 4종을 built-in image_gen의 이미지 편집 모드로 다시 그렸다. 생성 입력에는 각 v1 원화와 해당 스테이지의 현재 배경 또는 스크린샷을 사용했다. 새 원화는 `decor_*_generated_v2.png`이고 v1 원화는 이력 비교용으로 보존한다.

| 원화 | 생성 지시의 핵심 |
| --- | --- |
| `decor_flower_generated_v2.png` | 기존 꽃 한 송이의 실루엣과 크기를 유지하면서 선명한 핫핑크 꽃잎, 금빛 꽃술, 에메랄드 줄기와 잎으로 재화. 무지개 언덕의 둥근 동화풍 음영, 진한 색상 윤곽, 투명 배경. |
| `decor_grass_generated_v2.png` | 기존 낮고 넓은 풀 포기 실루엣을 유지하면서 밝은 라임·청록 잎과 또렷한 명암으로 재화. 무지개 언덕의 전경 수풀과 같은 광원·윤곽, 투명 배경. |
| `decor_rock_generated_v2.png` | 낮고 둥근 바위 한 덩어리를 안개 골짜기의 크림색 햇빛과 서늘한 청회색 그림자에 맞춰 재화. 단순한 동화풍 면과 깔끔한 윤곽, 투명 배경. |
| `decor_sign_generated_v2.png` | 기존 오른쪽 화살표 표지판의 실루엣을 유지하면서 밝은 꿀색·주황색 나무와 청록색 그림자로 재화. 쓰나미 마을의 따뜻한 집·울타리와 어울리도록 하고, 런타임 좌우 반전을 위해 오른쪽 화살표로 저장. 투명 배경. |

재생성: `node scripts/build-s6-decor-assets.js`

빌드 스크립트는 흐린 생성 후광을 제거하고 원화의 풀컬러 RGB와 가장자리 알파를 보존한다. 출력 캔버스 크기와 게임 내 배치 크기는 이전과 같다. 제한 팔레트 양자화와 장식별 표시 투명도는 적용하지 않는다. 최종 결과는 `references/s6-decor-final-contact-sheet.png`에서 확인할 수 있다.
