# 구멍 코스 원화

2026-10-22 이 대화의 built-in imagegen으로 제작했다. 사용자의 구멍 난 둥근 몸·긴 팔다리 스케치를 기준으로 6포즈와 밝은 동굴 협곡 배경을 생성했다.

정확한 프롬프트는 prompts.json, 원화는 hole-poses.png와 canyon.png, 조립 범위·공통 배율은 frames.json이다. `npm run hole:assets`는 원본 알파를 유지하고 동일 배율·발 기준선 112의 128×128 시트, 배경과 선택 미리보기를 만든다. 의미를 바꾸는 이미지 편집은 수행하지 않았다.
