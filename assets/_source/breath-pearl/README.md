# 숨방울 진주

스테이지 5 물에 잠긴 마을 전용 수중 수집물입니다. 첫 획득 시 최대 잠수 시간이 4초 늘고 숨 게이지가 가득 차며, 이후 진주는 다시 숨을 채웁니다.

`breath_pearl.png`는 내장 `image_gen`으로 생성한 투명 원화입니다. 프롬프트 요약: *A single compact storybook air bubble collectible enclosing a luminous ivory-gold pearl in a seafoam scallop cradle, dark-plum outline, bright turquoise highlights, readable at 60px, genuine transparency; no text or scene.*

`npm run breath-pearl:assets`로 128×128px 게임용 이미지와 앵커를 다시 생성합니다.
