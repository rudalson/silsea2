# 89% 구운 감자 애니메이션 원본

둥근 갈색 몸통, 짧은 다리, 짙은 갈기와 꼬리, 분홍 주둥이 및 큰 눈을
유지하며 실세아와 같은 프레임 안정성 기준으로 정리한 동작입니다.

- `atlas-green.png`: 이미지 생성 도구로 다듬은 8×8 원본 동작 시트.
- `flight-green.png`: 몸체를 고정하고 날개 관절을 움직이는 전용 3×2 비행 시트.
- `horn.png`: 기존 구운 감자 원화에서 보존한 뿔. 유니콘 파생 시트에 사용합니다.
- `frames.json`: 14개 동작의 프레임 수(총 66개), 눈 주변 영역 및 원본 추출 좌표.

## 재생성

저장소 루트에서 `npm run potato:assets`를 실행합니다. 개별 프레임과 기본
시트, 유니콘 파생 시트 및 전용 수영 시트를 갱신합니다.
`npm run spritesheets`로 공용 접촉 시트도 다시 만들 수 있습니다.

원본의 초록 배경과 고립된 효과선을 제거한 뒤 연결된 실루엣을 추출합니다.
격자선에서 살짝 벗어난 발이나 꼬리가 잘리지 않도록 실루엣 좌표를 사용하며,
동작별 바운딩 박스에 맞춰 몸체를 늘이지 않고 일정한 배율을 유지합니다.
지상 포즈는 발 기준선을 맞추고, 비행 포즈는 눈을 기준으로 정렬합니다.

대기는 하나의 몸체 그림과 짧은 눈 깜빡임으로 구성합니다. 발구르기와 착지는
관절 포즈로 표현하며, 런타임에서 캐릭터 전체를 늘이거나 줄이지 않습니다.
`roll` 키는 기존 게임과의 호환을 위해 유지하며, 오른쪽을 보는 이동 동작입니다.
수영은 전용 패들링 포즈를 사용하고 달리기 시트로 덮어쓰지 않습니다.

## 검증

- `npm test`: 실세아·구운 감자 기본/유니콘 대기 픽셀 안정성, 눈 깜빡임,
  단발 동작 유지, 66개 개별 프레임과 런타임 시트 일치, 투명 여백 및 발 기준선.
- `npm run validate:assets`: 팔레트, 실루엣, 방향, 뿔 연결 및 시트 규격.
- `npm run build` 및 `npm run validate:runtime`: 프로덕션 빌드와 로컬 에셋 연결.
