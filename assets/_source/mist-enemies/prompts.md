# Mist village enemy sources

Generated with the built-in `image_gen` tool, with `transparent_background: true`.
The original transparent images are preserved as `lantern-goblin-sheet.png` and
`dew-snail-sheet.png`. `npm run mist:enemies` slices the empty gutters, scales
each character's poses consistently, aligns the 16 px baseline, and builds
the runtime animation strips. Both source characters face left.
