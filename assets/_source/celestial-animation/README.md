# 선라이트 · 문라이트

사용자가 제공한 2026-09-13 손그림을 바탕으로 2026-09-29에 추가했습니다.
내장 image_gen으로 각각 4×4 원화 시트를 생성하고, 기본·유니콘·페가수스·알리콘 네 형태로 편집했습니다. 프롬프트는
[PROMPTS.md](PROMPTS.md)에 보관합니다.

## 캐릭터

- **선라이트 / Sunlight**: 크림색 털, 금빛·살구빛 물결 갈기, 꿀빛 눈과
  발굽. 날개 끝에 작은 해가 새겨진 밝고 용감한 친구입니다.
- **문라이트 / Moonlight**: 은보라색 털, 은빛 줄기가 흐르는 남색 갈기,
  사파이어빛 눈. 날개 끝의 초승달이 특징인 수줍지만 강하고 영리한
  친구입니다. 원안의 초승달을 좋아하는 성격과 ‘문샤인 빔’ 설정을
  캐릭터 세계관으로 보존합니다.

두 캐릭터는 뿔과 날개 없이 시작합니다. 유니콘 아이템을 얻으면 뿔만,
페가수스 아이템을 얻으면 문양 있는 날개만, 알리콘이 되면 둘 다 보입니다.
비행·방어·돌파 능력은 기존 게임과 동일하게 아이템으로 활성화됩니다. 문샤인 빔은 이번
캐릭터 외형 추가의 전투 기능에는 포함하지 않았습니다.

## 파일과 재생성

- `sunlight-atlas.png`, `moonlight-atlas.png`: 뿔과 날개가 모두 있는 알리콘 원본.
- `*-base-atlas.png`: 뿔·날개 없는 기본형.
- `*-unicorn-atlas.png`: 뿔만 있는 유니콘형.
- `*-pegasus-atlas.png`: 날개만 있는 페가수스형.
- `*-frames.json`: 연결된 실루엣 추출 좌표, 고정 배율, 동작별 포즈 순서.
- `../../characters/sunlight`, `../../characters/moonlight`: 런타임 PNG 시트와 개별 프레임.
- `../../../references/celestial-character-poses.png`: 전체 32개 포즈 미리보기.
- `../../../references/celestial-character-forms.png`: 두 캐릭터의 기본·유니콘·페가수스·알리콘 순서별 미리보기.
- 손그림은 `references/images/sunlight-reference.jpg`, `moonlight-reference.jpg`.

`npm run celestial:assets`로 128×128 프레임, 캐릭터별 40개 시트,
앵커와 검토 이미지를 재생성합니다. 각 캐릭터에 고정 배율을 적용하고,
발 기준선을 112px에 맞추며, 모든 뿔·날개·꼬리에 투명 여백을 둡니다.
대기·착지·피격·점프·낙하·달리기·비행·방어·수영·승리·변신 3종을 지원합니다.
일부 동작은 같은 포즈를 유지하거나 왕복 재생합니다.

기본·유니콘·페가수스·알리콘마다 시트가 분리되어 있습니다. 게임의
형태 전환에 따라 시트를 바꾸고 공용 날개 중복 표시는 막습니다.
팔레트는 `data/palette.js`의 sunlight, moonlight 그룹을 사용합니다.

`npm test`, `npm run validate`, `npm run build`, `npm run validate:runtime`.
캐릭터 5명 선택, 둘째 줄 방향키 이동, 시트 프레임 수와 투명 여백,
날개 중복 표시 방지, 기존 물리와 변신 규칙을 검사합니다.
