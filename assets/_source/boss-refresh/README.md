# 스테이지 보스 원화 통일

감자 대왕, 랜덤 대왕, 투명 대왕, 훌라후프 대왕, 물 대왕의 기존 정체성을
유지하며 어린이 게임에 맞게 밝고 둥근 동화풍으로 다시 제작했습니다.
원화는 내장 imagegen 도구로 제작했으며, 기존 제작 프롬프트는 `prompts.json`에
보존했습니다. 훌라후프 대왕을 제외한 각 `*_king.png`가 채택한 원본 아틀라스입니다.

훌라후프 대왕은 스테이지 4의 원화풍 배경에 맞춰 다시 채색했습니다.
`hula_king_storybook_anchor.png`를 기준으로 일곱 대표 포즈를
`hula_king_storybook_poses.png`에 그렸고, 발사체와 겹치지 않는 투척 자세는
`hula_king_storybook_throw.png`에 따로 보존했습니다.
`build-hula-storybook.js`가 대표 포즈를 기존 7개 상태·37프레임으로 조립하며,
`build-boss-refresh.js hula_king`과 전체 보스 생성에서도 같은 결과를 냅니다.
새 원화 프롬프트의 핵심은 분홍 왕·왕관·훌라후프 형태를 유지하면서,
쓰나미 마을의 따뜻한 햇빛과 장밋빛 붓질·부드러운 명암을 일곱 포즈에
일관되게 적용하고 투명 배경으로 분리하는 것입니다.

`npm run boss:assets`로 5종·35개 시트·179개 프레임을 재생성합니다.
각 원본 전체에 하나의 배율을 적용하며, 개별 포즈를 실루엣 크기에 맞춰
늘이거나 줄이지 않습니다. 다섯 보스의 대기 실루엣 높이는 84px,
발 기준선은 112px입니다. 게임의 기존 1.5배 표시와 충돌 크기를 유지합니다.

대기는 동일 몸체에 눈꺼풀 영역만 교체합니다. 공격 준비·피격·패배는
표정과 관절 자세로 표현하고, 패배 후에는 편하게 앉아 웃습니다.
투명 대왕의 숨기와 물 대왕의 잠수에는 고정 크기의 투명도 전환을 적용합니다.
투명 대왕의 기억 잔상도 새 몸체를 사용하며 확대되는 효과를 제거했습니다.

기존 환경용 제한 팔레트는 매끈한 원화에 얼룩을 만들기 때문에, 각 보스
원본에서 디더링 없이 추출한 색상표를 모든 동작에 공통 적용합니다.
`palette.json`은 검증에도 사용합니다. 이전 P10~P13 제작 스크립트로
효과를 다시 만들어도 마지막에 새 보스 원화를 복원합니다.

검증: `npm test`, `npm run validate:assets`, `npm run validate:integration`,
`npm run build`, `npm run validate:runtime`. `test-boss-art.js`는 모든
179프레임의 기준선·여백·시트 일치, 다섯 보스의 동일 대기 높이,
눈 이외 영역의 픽셀 안정성과 애니메이션 프레임 수를 검사합니다.

검토 자료: `references/bosses-refined-overview.png`, 보스별
`references/*_king-refined.png`, 실제 스테이지의 `references/boss-runtime-*.png`.
