# 메롱 왕국 N2 원화

사용자 스케치의 큰 입·긴 팔다리·궁전 테마를 바탕으로 내장 imagegen으로 제작했다.
`merong-poses.png`는 대기·예고·공격·약점·피격·패배 6포즈 원본,
`kingdom.png`는 왕국 배경 원본이며 정확한 프롬프트는 `prompts.json`에 보존한다.
`node scripts/build-merong-assets.js`로 공통 배율·128px 프레임·발 기준선 112px를
유지한 6개 시트와 배경·선택 미리보기를 재생성한다. 긴 혀와 공격 예고는
게임 코드의 동일한 기하 정보로 표시·판정한다. 현재 각 상태는 단일 포즈를 사용한다.
