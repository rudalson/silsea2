# 대피소 보호막

`shelter_shield.png`는 built-in `image_gen`으로 만든 투명 원화입니다. 스테이지 4 화면의 색감을 참고해 청록 물결 리본과 금빛 별을 그렸고, 주인공이 보이도록 중앙을 비웠습니다.

프롬프트 요약: *A light storybook shield frame with thin turquoise water ribbons, pale-gold accents and a four-point star crest; broad transparent center for the pony, pointed lower corners, no oval ring, no scene or text, genuine transparency.*

`npm run tsunami:shield`로 게임용 `fx_shelter_shield.png`를 다시 생성합니다.
