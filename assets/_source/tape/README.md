# 테이프 도시 N3 원화

스케치의 테이프 말이·긴 절단부를 바탕으로 이 대화의 built-in imagegen으로 제작했다.
`tape-poses.png`는 최초 6포즈 원본, `tape-poses-v2.png`는 셀 밖으로 돌출되던 절단부를 고쳐 여백을 확보한 최종 원화이며 `city.png`는 도시 배경 원본이다.
정확한 최종 프롬프트는 `prompts.json`에 보존한다.
`npm run tape:assets`는 공통 배율·128px 프레임·발 기준선 112px를 유지해 시트와 배경·미리보기를 재생성한다.
현재 상태별 단일 포즈이며 투사체·공격 예고·바닥 테이프는 같은 좌표를 사용하는 게임 코드로 표시한다.
