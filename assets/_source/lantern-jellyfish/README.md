# 초롱 해파리

스테이지 5 물에 잠긴 마을을 위한 적 캐릭터 원화입니다. `lantern_jellyfish.png`는 내장 `image_gen`으로 생성한 투명 배경 원본입니다. 깊은 잠수 통로에 등장하며, 가까워진 플레이어에게 두 번 금빛 예고를 보인 뒤 짧게 돌진합니다.

프롬프트 요약: *A single mischievous lantern jellyfish for a colorful submerged storybook village game; translucent turquoise bell, warm golden inner glow, coral-pink scalloped rim, short ribbon tentacles, large expressive eyes, dark-plum outlines, compact readable silhouette, genuine transparency; no scene, text, or other creatures.*

`npm run lantern-jellyfish:assets`로 투명 원화를 잘라 128×128px 게임용 대기 이미지 `assets/enemies/lantern_jellyfish/lantern_jellyfish_idle.png`를 만듭니다.
