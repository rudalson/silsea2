# 테이프 도시 전용 타일 원화

내장 `image_gen`으로 두 재질 원화를 별도로 생성했습니다. `paper.png`는 크림색 종이층 단면이고 `tape.png`는 금빛 접착 리본 재질입니다. `bg_tape_far.png`는 팔레트·붓질 참조로만 사용했습니다. 정확한 프롬프트와 보존 파일의 SHA-256은 `prompts.json`에 있습니다.

`node scripts/build-tape-tiles.js`로 게임용 `assets/tiles/tape_tileset.png` 및 `.json`을 조립합니다. 기존 프레임 이름과 64px 타일 크기를 유지하는 16프레임 아틀라스이며, 프레임마다 2px 가장자리 확장을 넣습니다.

- 생성 재질을 64px로 줄이고 가장자리 8px를 부드럽게 연결해 반복 이음새를 맞춥니다.
- 바닥 윗면은 금빛 테이프, 얇은 청록 띠와 하이라이트로 마감합니다. 단면·변형 단면·좌우 끝·발판·안쪽 모서리·경사면을 같은 재질로 구성합니다.
- 기본 단면과 변형 단면의 경계 픽셀을 맞춰 서로 섞어도 이음새가 생기지 않게 합니다.
- 이동 다리·리프트도 같은 발판 프레임을 사용합니다.
- 큰 배경, 기존 공용 잔디 타일, 실제 충돌 배치 및 감속 구간은 변경하지 않습니다. 선택 화면의 테이프 도시 미리보기만 새 타일로 갱신합니다.

미리보기: `references/tape-environment-preview.png`, `references/tape-tileset-strip.png`.
