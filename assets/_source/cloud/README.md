# 구름 코스 원화

2026-10-22 이 대화의 built-in imagegen으로 제작했다. 사용자 스케치의 울퉁불퉁한 구름 몸체·긴 팔다리·뾰족한 입을 밝은 동화풍 대왕으로 제작했다. 6포즈와 하늘 성 배경의 정확한 프롬프트는 prompts.json에 보존했다.

`npm run cloud:assets`는 cloud-poses.png의 원본 알파를 유지하여 동일 배율·발 기준선 112의 128×128 시트, sky.png에서 2048×720 배경과 640×360 미리보기를 만든다. 프레임 범위·배율은 frames.json이다. 의미를 바꾸는 후처리는 하지 않았다.
