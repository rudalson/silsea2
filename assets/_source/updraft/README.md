# 무지개 언덕 상승기류 원화

2026-10-02 사용자 화면을 기준으로 내장 image_gen 이미지 편집 모드에서 상승기류 2종을 새로 생성했다. `fx_updraft_wind_generated_v2.png`는 기존 가느다란 바람 원화·사용자 화면·무지개 언덕 전경을 참고해 바닥의 유기적인 나선부터 넓게 감겨 올라가는 바람 기둥까지 새로 그린 원화다. `fx_updraft_curl_generated_v1.png`는 첫 원화의 색과 명암을 참조해 생성한 개별 바람 리본이다.

프롬프트 핵심: 선명한 동화풍 배경과 어울리는 민트·청록·하늘색·아이보리의 부드러운 음영, 둥글고 명료한 실루엣, 지면에서 위로 이어지는 겹친 나선, 실제 투명 배경. 화살표·글자·캐릭터·배경·분리된 평면 타원·가느다란 낙서 형태를 제외한다. 보조 리본은 같은 붓질을 유지하며 회전하면서 상승할 수 있는 한 조각으로 만든다.

재생성: `node scripts/build-updraft-assets.js`

빌드에서는 원화의 색과 알파를 유지하고 런타임 캔버스 크기로만 조정한다. 게임에서는 기둥을 중심에 두고 보조 리본을 나선 경로로 위로 흐르게 한다.
