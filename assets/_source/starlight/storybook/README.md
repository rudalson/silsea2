# 별빛 숲 플레이 배경 — 동화풍

내장 `image_gen` 도구로 생성. 화풍 참조는 `assets/backgrounds/stage_preview_starlight.png`입니다. 최종 원본 네 장은 이 폴더에 보관합니다.

- `bg_starlight_far.png`: 보랏빛 하늘, 달, 먼 언덕 → 같은 이름의 `assets/backgrounds/` 런타임 배경
- `bg_starlight_mid.png`: 투명 배경의 둥근 민트 나무 → 같은 이름의 `assets/backgrounds/` 런타임 배경
- `bg_starlight_near.png`: 투명 배경의 낮은 덤불과 별꽃 → 같은 이름의 `assets/backgrounds/` 런타임 배경
- `starlight_decor.png`: 별나무, 달빛 나뭇가지, 반딧불, 별꽃 → `assets/decorations/decor_{star_tree,moon_branch,firefly,star_flower}.png`

`npm run starlight:assets`로 재생성합니다. 배경은 2048×720, 전경 식생은 y=500 아래에 맞춥니다. 원본의 색상과 부드러운 알파를 유지하며 기존 2px 경계 처리와 런타임 좌우 반전 반복을 사용합니다. 장식 시트의 기본 경계는 가로 50%, 세로 64%입니다. 반딧불은 위쪽 별나무의 밑부분이 섞이지 않도록 세로 70%부터 별도로 추출합니다. 각 장식에는 투명 여백을 두며, 반딧불의 분리된 가로선 조각은 에셋 검증에서 검사합니다. 지형은 기본 잔디의 초록·흙색을 유지하고 달빛 점을 추가합니다. 충돌·레벨 배치·게임 규칙은 변경하지 않습니다.
