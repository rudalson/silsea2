# 이전 실비아 외형 자료 (사용 중단)

이 폴더는 2026-09-11의 짧은 갈기 원화와 프레임 배치 기록입니다.
당시 생성 프롬프트에 들어간 수컷 설정은 잘못된 설정이었습니다.
2026-09-15 사용자 요청에 따라 **실비아는 암컷, 실세아는 수컷**으로
정정했고, 이 폴더의 원화는 현재 런타임 재생성에 사용하지 않습니다.

현재 채택 원본 및 재생성 방법은 `../sylvia-animation/README.md`를
참조하세요. `npm run sylvia:assets`가 새 외형과 모든 동작을 생성합니다.
기존 뿔 원형 `sylvia-horn.png`는 새 원본 폴더의 `horn.png`로 보존했습니다.
