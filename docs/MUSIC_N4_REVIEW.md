# N4 피아노 나라·음악 대왕 검수 기록

작성일: 2026-10-22 · 구현·자동 검사·대표 조합 브라우저 완주 완료

9번 `level-09`를 등록하고 8→9 해금, 코스와 음악 대왕, 게이트·진행 저장을 연결했다. 기존 저장 키는 유지한다. 자발적 5초 정지는 N1 추천 해석을 구현한 것으로 영상 음성의 미확인 규칙을 확정한 것은 아니다.

## 구현

- 16,384px, 입구 → 건반 연습 → 멜로디 길 → 하늘 건반 → 공연장 접근 → 대왕 무대의 6구간.
- 필수 정지 문 3개, 낭떠러지 2개, 이동 발판 1개, 체크포인트 6개, 세 변신과 선택 비밀 발코니.
- 지상 진입 → 1.5초 예고 → 입력을 놓고 정확히 5초 → 문 열림. 처음에는 실패 피해가 없고 본 구간은 재도전당 피해 1회다. 공중에서는 시작하지 않으며 실제 충돌 문으로 비행 우회를 막는다.
- 완료한 필수 문은 부활·데이터 재로드 후 보존한다. 새 시작은 초기화한다. 일시정지·변신 연출 중 시간은 멈춘다.
- 같은 `RhythmSignal`을 필드와 보스에서 사용한다. 문구·초 표시·접근성 알림과 별도 예고/정지/해제 효과음 3종을 제공한다. 쉬운 모드는 예고를 늘리고 5초는 유지한다.

대왕 HP는 3이다. 1단계 낮은 음표, 2단계 낮은 음표 후 5초 정지, 3단계 낮음→높음→낮음 뒤 5초 정지를 사용한다. 정지 중에는 공격 음표를 모두 정리하고 안전 바닥에서 기다린다. 실패는 한 번 피해 후 재안내한다. 연주와 정지가 끝나면 약점을 3.4/3.5/3.6초 열며 기본 점프로 하강 중 머리를 밟는다. 쉬운 모드는 음표 속도 0.8배·예고 1.35배·약점 1.3배다. 날개는 음표를 막을 수 있다. 부활 시 대왕 HP·단계·정지를 초기화하고 처치 시 모든 공격을 정리한다.

## 이미지·소리

**built-in imagegen**으로 6포즈와 궁전 배경을 제작했다. 원화·정확한 프롬프트·조립 메타데이터는 [assets/_source/music](../assets/_source/music/README.md), [prompts.json](../assets/_source/music/prompts.json)에 보존했다. 시트는 각 128×128 RGBA, 공통 배율·발 기준선 112px이며 [6포즈 검수 이미지](../references/music-poses-review.png)로 확인한다. 배경은 2048×720, 선택 미리보기는 640×360이다. `npm run music:assets`로 조립한다.

전용 신호 WAV 3종은 `npm run music:audio`로 생성한다. 기존 효과음·음악 파일을 다시 쓰지 않도록 생성기에 선택 키 옵션을 추가했다. 기존 BGM을 재사용하며 대왕 동작은 상태별 단일 포즈다. 음색의 사람 청취 평가는 아직 하지 않았다.

## 검증

`npm test`, `npm run test:music`, `npm run validate`, `npm run test:soak`, `npm run test:release` 통과. 플레이 9개·개발 5개, manifest 631키(시각 547·오디오 84), 로컬 런타임 파일 637개·외부 URL 0개다. 기존 큰 번들 경고는 남는다. Soak는 기존 풀·파티클·Scene 정리의 216,000프레임 모의 검사이며 신규 대왕의 60분 실기는 아니다. 캐릭터 변경이 없어 기존 spritesheets 재조립은 반복하지 않았다.

실제 Phaser 입력·중력·충돌을 사용하는 `/scripts/music-runtime.html?visualReview=level-09&debug=1&mute=1`에서 두 대표 조합을 완주했다. 기존 사용자 저장소를 임시 저장소와 분리하고 종료 시 복원한다.

양쪽에서 공중 우회 차단, 연습 무해 실패, 본 구간 피해 1회, 정확한 정지, 완료 문 부활·재로드 보존, 일시정지, 날개 방어, 약점 외 타격 거부, 세 단계 HP 1씩 감소, 보스 중 추락 복귀, 실제 게이트 진입과 9번 저장을 확인했다. 브라우저 오류·경고는 없었다. 일반 검사 대기 위치는 정지 안전 범위와 3단계 음표 최대 도달 범위를 모두 만족하도록 무대 왼쪽에서 64px로 잡았다.

자동 주행 시간은 사람의 목표 플레이 시간으로 사용하지 않는다. 실제 게임패드, 전체 캐릭터 조합의 신규 코스 실기, 어린이의 난이도·재미 평가는 미실시다. 다음 단계는 N5 구멍 코스다.
