# 테이프 도시 전용 적 2종 검수

검수일: 2026-10-24

## 적용 내용

- `tape_rollbug` / **테이프 말이**: 종이 심과 짧은 테이프 꼬리가 있는 금빛 몸통, 민트색 손발.
- `tape_boxling` / **박스 꼬마**: 금빛 포장 테이프가 붙은 크림색 상자, 라벤더 손발과 청록색 모서리.
- 내장 `image_gen`으로 투명 원화 각 6포즈를 제작했다. 원화·정확한 프롬프트·자르기 범위는 `assets/_source/tape-enemies/`에 보존한다.
- 각 캐릭터의 대기 2·보행 4·패배 2프레임을 128×128 시트와 개별 PNG로 조립했다. 캐릭터별 공통 배율, 112px 발 기준선, 원화 알파를 유지한다.
- 첫 감자 적 `(5056, 576)`은 테이프 말이, 두 번째 `(11264, 576)`는 박스 꼬마로 교체했다. 순찰 범위 80px, 기존 이동 속도와 40점, 쉬움의 두 번째 적 제거 규칙을 유지한다.
- 원화의 몸통 크기에 맞는 충돌 영역을 정의했다. 단순 순찰 여부를 공통 정의로 판단해 이동·지면 충돌·접촉 피해에 같은 분류를 사용한다. 기존 감자와 메롱 꼬마의 원화 방향은 유지한다.

## 자동 검사

- `npm run test`: 전체 테스트 통과. 신규 적의 배치·쉬움 제거·점수·실제 투명 픽셀·여백·기준선·서로 다른 원화 포즈·duration 매핑을 포함한다.
- `npm run validate`: 레벨·구조·core·mapping·에셋·통합 검사 통과. 적 350개 개별 프레임과 103개 시트 검증.
- `npm run build`, `node scripts/validate-runtime-build.js`: 프로덕션 빌드와 로컬 이미지·오디오 687개 참조 검사 통과.
- `npm run tape:enemies` 재실행 전후 시트·미리보기·메타데이터·등록 파일 11개의 SHA-256이 동일했다.
- `git diff --check`: 공백 오류 없음.

## 브라우저 실제 플레이

`/scripts/tape-runtime.html?visualReview=level-08&debug=1&mute=1`의 검사 완료:

- 원화 적 2종 로드, 좌우 경계에서 순찰 방향과 원화 반전 일치, 보행 애니메이션 실행.
- 각 적의 실제 물리 접촉으로 체력 1 감소, 실제 하강 밟기로 처치, 패배 애니메이션 실행과 종료, 중복 없는 40점 지급.
- 지상 테이프 0.6배 감속, 점프·비행 중 감속 해제.
- 필드 5구간과 두 낭떠러지를 낙사 없이 통과. 필드 이동 36.8초, 별 93개.
- 데이터 재로드 정리, 일시정지, 날개 방어, 보스 바닥 테이프, 약점 외 타격 거부와 세 단계 실제 점프 타격.
- 실패 후 재도전 초기화, 처치 후 공격·감속 정리, 실제 게이트 진입과 임시 저장 완료.
- 검사 중 사용자 기존 진행 기록 보존. 브라우저 warning/error 0건.

기존 테스트가 검증하는 쉬움 배치와 도형 fallback 계약도 유지한다. 이번 브라우저 완주는 기본 난이도·원화 모드에서 수행했다.
