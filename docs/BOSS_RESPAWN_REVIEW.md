# 부활 후 누적 보스 피해 보존

검수일: 2026-10-25

메롱·테이프·음악·구멍·구름 대왕은 플레이어가 사망하거나 추락해 체크포인트에서 부활해도 보스의 현재 HP와 그에 맞는 공격 단계를 유지한다. 부활 이벤트에서 HP를 최대치로, 단계를 1로 덮어쓰던 다섯 처리를 제거했다.

재도전 시 남은 공격과 예고는 정리하고 보스는 구역 재입장을 기다린다. 혀·테이프 조각과 바닥 감속·음표와 정지 신호·임시 구멍·돌풍과 빗방울 정리를 유지한다. 처치한 보스와 활성 게이트도 유지된다. 새로 시작한 스테이지는 정상 초기 체력을 사용한다.

검증:

- `npm test`: 전체 회귀 검사와 신규 보스 5종의 양 난이도·HP 3/2/1·반복 부활·재입장·공격 정리·처치 유지·새 플레이 초기화 통과.
- `npm run validate`, `git diff --check`: 레벨·구조·코어·에셋 매핑·에셋·통합 검증과 변경 형식 검사 통과.
- `npm run build`, `node scripts/validate-runtime-build.js`: 프로덕션 빌드와 로컬 이미지·오디오 723개 확인 통과.
- `/scripts/boss-respawn-runtime.html?visualReview=level-07&debug=1&mute=1`의 `level-07`부터 `level-11`까지 다섯 실제 게임 검사 COMPLETE. 보스 상태나 약점·타격 규칙을 강제로 바꾸지 않고 기본 점프로 타격했다.
  - 첫 타격 HP 3→2, 플레이어의 마지막 HP에 실제 피해를 주어 사망·체크포인트 부활 후 보스 HP 2·2단계 확인.
  - 두 번째 타격 HP 2→1, 추락·체크포인트 부활 후 보스 HP 1·3단계 확인.
  - 마지막 타격 HP 1→0, 플레이어 재사망 후 보스 처치·게이트 유지와 타격/처치 이벤트 중복 없음 확인.
  - 다섯 브라우저 오류·경고 없음. 검증 중 임시 저장을 사용해 사용자 진행 기록을 보존했다.

기존 각 스테이지 완주 검사도 체력·단계 보존을 기대하도록 수정했다. 첫 타격 뒤 부활하던 메롱·테이프·피아노 검사는 남은 두 번의 타격으로 완료하도록 변경했다.
