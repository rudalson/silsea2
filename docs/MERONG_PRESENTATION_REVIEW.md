# 메롱왕국 공격 표현과 바라보는 방향

검수일: 2026-10-26

- 문지기 여섯 곳의 공격 예고·점프 지시·휴식 안내 문구와 줄무늬 범위 상자를 제거했다. 메롱 대왕의 공격 범위 예고도 제거했다. 실제 혀는 공격할 때만 그리며 기존 피해 영역과 일치한다.
- 문지기는 볼을 부풀리는 두 표정과 작은 들숨 동작으로 공격 준비를 표현한다. 준비 시간·소리·쉬운 모드의 긴 준비·연습 문지기의 무피해·접근성용 숨김 안내는 유지한다.
- 문지기와 대왕은 대기·회복 중 주인공의 좌우 위치를 바라본다. 준비 시작 시 방향을 정하고 공격이 끝날 때까지 유지한다. 문지기는 몸을 제자리에 둔 채 입과 혀 시작점을 함께 반전한다. 대왕은 왼쪽이 기본인 원화와 동작 방향을 맞췄다.
- 도형 대체 모드도 눈·입 방향과 준비 동작을 적용했다. 부활·화면 이탈·완료·재로드 때 혀를 정리하며 보스 누적 피해 보존을 유지한다.

검증:

- `npm test` 통과. 새 검사는 원화/대체 도형·양쪽 초기 방향·높고 낮은 혀·고정된 몸 위치·양쪽 입 정렬·준비 중 무피해와 범위 표시 없음·실제 공격 피해·회복 후 방향 갱신·연습 무피해·대왕 반전을 확인한다.
- `npm run build`, `node scripts/validate-runtime-build.js` 통과. 새 외부 의존성이나 게임용 이미지 추가 없음.
- `npm run validate`, `git diff --check` 통과. 레벨·구조·코어·매핑·에셋·통합 검증 완료.
- 실제 브라우저 원화 모드 COMPLETE: 좌우 준비→반대편 이동에도 방향 고정→보이는 혀 피해→회복 후 회전, 31.2초·별 65개 필드 무추락 완주, 보스 3단계·사망 뒤 HP 보존·게이트·임시 저장.
- 실제 브라우저 대체 도형 모드 COMPLETE: 같은 좌우 공격 검사와 31.1초·별 57개 필드 무추락 완주, 접촉/밟기·보스·게이트·저장. 두 모드와 좌우 미리보기의 브라우저 오류·경고 없음. 사용자 기존 기록 보존.
- 검증 전용 진입점은 Phaser의 타이머 프레임 루프를 사용해 비활성 데스크톱 패널의 RAF 제한을 피한다. 순찰 검사는 원화와 대체 도형의 실제 생성 Y를 사용한다. 게임의 공격 상태·시간·피해 규칙은 변경하지 않는다.
