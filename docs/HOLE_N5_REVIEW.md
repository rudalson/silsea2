# N5 구멍 코스·구멍 대왕 검수 기록

작성일: 2026-10-22 · 구현·자동 검사·대표 조합 브라우저 완주 완료

10번 `level-10`을 추가해 9→10 해금과 기존 저장 호환을 연결했다. 16,384px의 6구간에 고정 낭떠러지 3개, 필드 개폐 다리 4개, 대왕 다리 2개, 이동 발판·세 변신·회복 체크포인트 7개·선택 비밀 전망대를 배치했다. 모든 개폐 다리는 타일맵의 실제 빈 공간을 채우는 충돌 객체다.

## 규칙과 대왕

필드 다리는 접근하면 1.5초 예고 → 2초 열림 → 3초 닫힘을 반복한다. 쉬운 모드는 예고 1.5배다. 예고 중에는 충돌이 유지되고, 열리면 표시와 충돌을 함께 해제한다. 양옆에는 고정 발판이 있으며 몸이 다리 복구 면에 걸쳐 있으면 빠져나올 때까지 복구를 미룬다. 일시정지 중 개폐 시간은 멈추고 부활·재로드는 닫힌 상태로 복원한다.

대왕 다리는 필드 자동 주기 대신 보스가 제어한다. 1단계 왼쪽 다리, 2단계 가까운 다리, 3단계 두 다리를 고정 위치에 예고한 뒤 연다. 쉬운 모드는 최대 1개만 연다. 열려 있는 동안 대왕은 집 위치 ±128px의 연속 고정 바닥에서 좌우로 움직인다. 두 구멍 사이 448px 안전 발판과 오른쪽 대왕 발판은 항상 남는다. 날개로 바닥 구멍을 막을 수는 없다.

공격이 끝나면 다리를 복구하고 대왕은 중앙으로 돌아와 멈춘다. 이때만 머리 약점이 열리며 변신 없이 기본 점프로 세 번 밟는다. 단계별 예고는 1.5/1.4/1.3초, 열림은 2.2/2.6/3초, 약점은 3.6/3.7/3.8초다. 쉬운 모드는 이동 0.8배·예고 1.35배·약점 1.3배다. 부활 시 HP·단계·위치·다리를 초기화하며 처치 시 필드와 보스의 모든 다리를 복구하고 개폐를 끝낸다.

## 이미지

**built-in imagegen**으로 [6포즈와 협곡 배경](../assets/_source/holes/README.md)을 만들었다. 정확한 [프롬프트 세트](../assets/_source/holes/prompts.json)와 프레임 메타데이터를 함께 보존했다. 원본 알파를 유지해 128×128 RGBA·공통 배율·기준선 112px로 조립했다. [6포즈 검수 이미지](../references/hole-poses-review.png), 배경 2048×720, 선택 미리보기 640×360을 등록했다. `npm run hole:assets`로 재조립하며 상태별 단일 포즈와 기존 효과음·BGM을 사용한다.

## 검증

`npm test`, `npm run test:hole`, `npm run validate`, `npm run test:soak`, `npm run test:release` 통과. 플레이 10개·개발 5개, manifest 639키(시각 555·오디오 84), 로컬 런타임 645파일·외부 URL 0개다. 원화 재조립의 관련 12파일 SHA-256은 불변이다. 기존 큰 번들 경고가 남고, 캐릭터 시트는 변경하지 않았다. Soak는 기존 자원 관리의 60분 등가 모의 검사다.

`/scripts/hole-runtime.html?visualReview=level-10&debug=1&mute=1`의 **구멍 코스 검증 실행**은 실제 Phaser 입력·중력·충돌을 사용한다. 필드를 자동 주행하고 실패 재현·대왕 접근·게이트 위치를 제어하며 임시 진행 저장소로 원래 기록을 보존한다.

양쪽에서 예고·열림 표시와 실제 충돌, 열린 구멍 추락·복귀, 일시정지, 필드 완주, 재로드 정리, 약점 외 타격 거부, 대왕 구멍 추락 시 초기화, 기본 점프 3타격·중복 타격 방지, 대왕 실제 좌우 이동, 난이도별 동시 구멍 수, 처치 후 바닥 복구·게이트·10번 저장을 확인했다. 브라우저 오류·경고는 없었다.

자동 주행은 사람의 목표 플레이 시간이나 재미 평가를 대신하지 않는다. 실제 게임패드·전체 캐릭터 조합 신규 코스 실기·어린이 평가는 미실시다. 다음은 N6 구름 코스다.
