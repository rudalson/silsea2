# N6 구름 코스·구름 대왕 검수 기록

작성 시작: 2026-10-22 · 최종 검증: 2026-10-23 · 대표 두 조합 전체 완주 완료

11번 `level-11`은 18,432px의 입구 → 하늘 산책 → 구름 다리 → 상승기류 → 무지개 접근 → 구름 성으로 구성했다. 10번 클리어로 해금되며 11번 뒤에는 다음 레벨이 없다. 고정 낭떠러지 4개, 이동 구름 2개, 상승기류 2개, 회복 체크포인트와 선택 전망대를 배치했다. 기존 진행 저장 형식을 유지한다.

## 코스와 전투

정적 지형의 충돌 상단과 같은 높이에 밝은 구름 테두리를 그리고 이동 구름은 기존 공통 지형 시스템을 사용한다. 필수 날개 전의 낭떠러지는 기본 점프로 건너는 192px다. 640px 기류 구간에는 384px 고정 보조 발판을 두어 양쪽 빈 공간을 128px로 줄였다. 이동 구름은 선택 경로에 배치해 빈 게이지 경로가 발판 주기에 의존하지 않는다. 새 기류는 중력보다 큰 가속도를 사용하고 착지하면 비행 게이지가 회복된다.

대왕은 1단계 돌풍, 2단계 고정 예고 위치의 비 1열, 3단계 돌풍 뒤 3열 비를 순서대로 사용한다. 쉬운 모드는 비 1열·바람 0.65배·비 속도 0.8배·예고 1.35배·약점 1.3배다. 공격마다 예고 위치·방향을 고정하고 화살표·세로 표시·접근성 문구로 알린다.

돌풍은 이동 목표 속도에 130~155px/s를 더한다. 키를 놓아도 밀리고 반대 방향 입력으로 걸을 수 있으며 무대 끝 96px에서는 밀림을 멈춘다. 바닥은 보스 구간 전체에 고정되어 있다. 돌풍에는 접촉 피해가 없고 날개로 차단하지 않는다. 비는 실제 이동 전후 세로 범위를 검사하며 앞쪽 빗방울을 날개로 막을 수 있다. 바람과 비가 동시에 나오지 않는다.

공격 뒤 모든 비·바람을 정리하고 대왕을 y=576으로 내려 약점을 3.6/3.7/3.8초 연다. 기본 점프의 하강 머리 밟기로 HP 1씩 세 번 줄인다. 부활은 HP·단계·위치·모든 공격을 초기화하고, 일시정지·변신 연출 중 공격 시간은 멈춘다. 처치 후 실제 게이트에 들어가 최종 클리어를 저장한다.

## 이미지와 재생성

**built-in imagegen**으로 [6포즈와 하늘 성 배경](../assets/_source/cloud/README.md)을 제작했다. [정확한 프롬프트 세트](../assets/_source/cloud/prompts.json), 원본 알파와 프레임 메타데이터를 보존했다. 시트는 각 128×128 RGBA·공통 배율·발 기준선 112px, 배경은 2048×720, 선택 미리보기는 640×360이다. [6포즈 검수 이미지](../references/cloud-poses-review.png)를 제공하고 `npm run cloud:assets`로 조립한다. 각 상태는 단일 포즈이며 기존 BGM과 경고 효과음을 사용한다.

## 검증 범위

`npm test`, `npm run test:cloud`, `npm run validate`, `npm run test:soak`, `npm run test:release`로 규칙·배치·파일·빌드를 확인했다. 플레이 11개·개발 5개, manifest 647키(시각 563·오디오 84), 로컬 런타임 653파일·외부 URL 0개다. 기존 번들 크기 경고는 남는다. Soak는 기존 자원 관리의 60분 등가 모의 검사이며 대왕의 60분 실기가 아니다.

`/scripts/cloud-runtime.html?visualReview=level-11&debug=1&mute=1`은 실제 Phaser 입력·중력·충돌을 사용한다. 빈 게이지 회복·기본형 보조 경로·필드 완주·돌풍 이동과 반대 조작·일시정지·실패 복귀·날개 비 방어·세 단계 기본 점프·최종 게이트와 저장을 검사한다. 사용자 기록은 임시 저장소로 분리하고 복원한다.

양쪽 모두 빈 게이지 기본형 기류 경로, 착지 회복, 실제 돌풍 이동·반대 조작, 날개 비 방어와 HP 보존, 기본 점프 3타격, 실패 초기화, 최종 게이트와 사용자 기록 보존을 통과했다. 도형의 작은 충돌 폭에 맞춰 검증 캐릭터를 빗방울 앞 24px에 두었으며 이는 보스 판정 변경이 아니다. 브라우저 오류·경고는 없었다. 원화 재생성 12파일 SHA-256은 불변이다.

`&bossOnly=1`은 필드를 생략하는 보스 전용 재현 모드이며 결과에 생략 사실을 표시한다. 위 표는 필드를 포함한 최종 전체 검사 결과다. 실제 게임패드, 전체 캐릭터 조합의 신규 코스 실기, 어린이의 난이도·재미 평가는 미실시다. 자동 주행 시간은 사람의 목표 플레이 시간으로 사용하지 않는다.
