# N3 테이프 도시·테이프 대왕 검수 기록

작성일: 2026-10-22 · 구현·자동 검사·대표 조합 브라우저 완주 완료

## 구현 결과

8번 `level-08` 테이프 도시를 캠페인에 추가했다. 기존 7번 메롱 왕국을 클리어하면 해금된다. 기존 저장 키와 기록은 유지하며 현재 마지막 스테이지는 8번이다. 다음 9번 피아노 나라는 아직 등록하지 않았다.

- 14,336px, 도시 입구 → 테이프 연습 → 리본 거리 → 이동 작업장 → 작업장 접근 → 대왕 전투의 6구간.
- 지상 테이프 9개, 실제 낭떠러지 2개, 이동 발판 2개, 기본 체크포인트 5개, 변신 3종, 별 113개와 선택 비밀 공간 1개.
- 지상 가로 속도는 일반 0.6배·쉬움 0.8배다. 점프·비행·테이프 이탈 중에는 즉시 기본 배율로 돌아오며 점프 높이를 낮추거나 조작을 봉쇄하지 않는다.
- 첫 낭떠러지는 기본 점프로 통과하며, 넓은 두 번째 낭떠러지 전에는 날개와 회복 체크포인트·이동 발판을 둔다.
- 쉬운 모드는 추가 회복 체크포인트, 적 1개 제거, HP +2, 비행 소모 0.65배, 이동 발판 속도 0.8배를 적용한다.

스케치의 테이프 말이·길게 나온 절단부를 대왕 외형에 반영했다. 공격 순서와 수치는 개발 계획의 제안을 구현한 것으로, 영상 음성에만 있는 추가 규칙을 확인한 것으로 간주하지 않는다.

## 보스 전투

작업장에 들어가면 대왕이 나타난다. HP는 3이며 유효 타격마다 다음 단계로 전환한다.

| 단계 | 공격 | 공격별 예고 | 약점 시간 |
|---|---|---|---|
| 1 | 낮은 테이프 조각 1회 투척 | 1.2초 | 3.2초 |
| 2 | 예고한 바닥에 테이프 1개 설치 | 1.2초 | 3.3초 |
| 3 | 바닥 테이프 2개 → 낮은 조각 → 높은 조각 | 1.1초 | 3.4초 |

연속 공격 사이에는 0.45초를 둔다. 조각은 일반 300px/s, 3단계 330px/s이며 2.3초 뒤 사라진다. 낮은 조각은 점프나 날개 방어, 높은 조각은 지상 대기로 피할 수 있다. 이동 전후 범위를 함께 검사해 낮은 FPS에서 짧은 조각이 플레이어를 건너뛰지 않게 했다.

바닥은 설치 전 사각형과 느낌표로 예고하고 그 위치를 고정한다. 바닥 테이프 자체에는 HP 피해가 없다. 보스 양옆 320px의 머리 접근 길을 남기고, 두 테이프 사이에는 112px의 안전 바닥을 둔다. 공간이 부족하면 설치 개수를 줄인다. 쉬운 모드는 최대 1개, 조각 속도 0.8배, 예고 1.35배와 약점 1.3배다.

공격 후 테이프가 절단부에 걸리면 모든 조각·설치 테이프를 지우고 머리 약점을 연다. 기본 점프의 하강 중 머리 밟기만 유효하다. 한 타격에 HP 1만 줄고 즉시 약점을 닫는다. 부활 시 HP·단계·공격·임시 감속을 초기화하며, 처치 후 실제 무지개 게이트에 들어가야 완료된다.

정적·임시 테이프는 `CourseMechanicsManager`의 같은 감속 판정을 사용한다. 임시 구역은 소유자별로 등록·해제하므로 재로드·부활·처치·Scene 종료 후 감속을 남기지 않는다. 보스 시간·투사체·테이프 수명은 Scene 업데이트 delta로 진행해 일시정지 중에 멈춘다.

## 이미지와 재생성

이 대화의 **built-in imagegen**으로 대왕 6포즈와 도시 배경을 제작했다. 셀 경계를 넘던 절단부를 별도 편집 호출로 수정해 최종 원화를 만들었다.

- [원화 설명](../assets/_source/tape/README.md), [최종 프롬프트 세트](../assets/_source/tape/prompts.json), [프레임 메타데이터](../assets/_source/tape/frames.json).
- 최종 원화: `assets/_source/tape/tape-poses-v2.png`, `city.png`. 최초 포즈는 편집 입력으로 보존했다.
- 보스: `assets/enemies/tape_king/tape_king_{idle,warning,attack,vulnerable,hurt,defeated}.png`, 각 128×128 RGBA·발 기준선 112px·공통 배율.
- 배경: `assets/backgrounds/bg_tape_far.png` 2048×720, 선택 미리보기: `stage_preview_tape.png` 640×360.
- [6포즈 검수 이미지](../references/tape-poses-review.png). 재조립 명령은 `npm run tape:assets`다.

도시 작업장이 가려지지 않도록 레벨 데이터의 `parallax.layerAlpha`로 기존 mid·near 전경을 숨겼다. 다른 레벨의 기본 불투명도는 1이며 도형 fallback은 기존 배경 표현을 사용한다. 바닥 테이프·예고·조각은 코드가 같은 좌표로 표시하고 판정한다.

현재 대왕의 각 상태는 단일 포즈다. 다중 프레임 동작과 전용 음악은 후속 미술·음향 보강 범위이며 기존 필드·보스 음악과 경고 효과음을 재사용한다.

## 실제 브라우저 완주

`/scripts/tape-runtime.html?visualReview=level-08&debug=1&mute=1`의 **테이프 도시 검증 실행**을 사용했다. 검증 페이지는 실제 Phaser 입력·중력·충돌·이벤트로 이동과 타격을 수행한다. 감속·방어·실패 재현 위치와 체크포인트 복귀·게이트 진입 위치는 코드로 제어하며, 필드는 자동 입력으로 끝까지 주행한다. 검증 중에는 별도 임시 진행 저장소를 사용하고 끝나면 원래 저장 관리자를 복구한다.

| 실제 조합 | 결과 |
|---|---|
| 실세아·일반·이미지·무음 | 전체 통과. 필드 자동 주행 38.7초, 별 93개, 낭떠러지 추락 0회 |
| 89% 구운 감자·쉬움·도형 fallback·효과 감소·무음 | 전체 통과. 필드 자동 주행 35.9초, 별 88개, 낭떠러지 추락 0회 |
| 선택 화면·이미지 검수 | 8/8 카드·미리보기·이름·설명·선택 점 표시, Z 시작, 도시 배경·대왕·공격 예고·별 약점 표시 확인 |

두 완주 모두 다음을 확인했다.

- 7→8 해금, 작업장 진입 전 보스 비활성, 처치 전 게이트 없음.
- 지상 감속과 실제 속도, 점프 즉시 해제·비행 중 해제, 전체 필드 구간과 보스 전 회복 체크포인트 통과.
- 재로드 후 이전 공격 표시·감속 정리와 일시정지 시간 보존.
- 약점 외 머리 타격 거부, 실제 날개 입력으로 조각 방어 및 HP 보존.
- 보스 바닥 테이프의 동일 감속과 점프 탈출, 실패 복귀 시 HP·단계·감속 초기화.
- 세 단계 모두 기본 점프로 HP 1씩 감소, 약점 시간 전에 공격·감속 정리, 일반 최대 2개·쉬움 최대 1개 설치.
- 처치 후 직접 게이트 진입·클리어·8번 저장, 사용자 기존 localStorage 기록 불변.

두 검사에서 브라우저 오류·경고는 없었다. 자동 주행 시간은 사람의 목표 플레이 시간으로 사용하지 않는다. 실제 게임패드, 모든 캐릭터 조합의 신규 코스 실기, 어린이의 난이도·재미 평가는 아직 수행하지 않았다.

다음 N4는 피아노 나라와 음악 대왕이다. 자발적 5초 정지라는 N1 추천 해석과 영상 음성의 추가 규칙은 여전히 미확정 사항으로 유지한다.
