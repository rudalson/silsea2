# N2 메롱 왕국·메롱 대왕 검수 기록

작성일: 2026-10-22

## 구현 범위

7번 스테이지 `level-07`을 일반 캠페인에 추가했다. 6번 클리어로 해금되며 기존 저장 키와 1~6번 기록은 유지한다. 다음 단계의 8번은 아직 등록하지 않았으므로 현재 마지막 스테이지는 7번이다.

- 12,288px 코스: 왕국 입구 → 무해한 혀 연습 → 혀 다리 → 높낮이 통로 → 회복 체크포인트 → 궁전 전투.
- 필드 혀 장치 6개, 실제 바닥이 끊긴 낭떠러지 2개, 뿔·날개·알리콘 아이템, 기본 체크포인트 5개, 선택 별 101개와 지붕 비밀 공간 1개.
- 짧은 첫 낭떠러지는 기본 점프로 통과한다. 두 번째 낭떠러지 전에는 날개와 회복 지점이 있으며 쉬운 모드는 추가 체크포인트와 체력·비행 보정을 적용한다.
- 궁전 구간 진입 전에는 보스 본체·충돌을 비활성화한다. 진입 후 등장하고 공격을 시작한다. 보스 처치만으로는 완료되지 않고 실제 무지개 게이트 진입이 필요하다.

스케치의 입·궁전·긴 팔다리를 테마로 옮겼다. 공격 순서와 세부 수치는 개발 제안의 구현이며, 영상 음성에만 있는 규칙을 확인한 것으로 간주하지 않는다.

## 전투와 판정

| 보스 HP / 단계 | 공격 | 공격별 예고 | 공격 시간 | 마지막 공격 후 약점 |
|---|---|---|---|---|
| 3 / 1 | 낮은 혀 1회 | 1.20초 | 0.60초 | 2.60초 |
| 2 / 2 | 낮은 혀 → 높은 혀 | 1.15초 | 0.60초 | 2.70초 |
| 1 / 3 | 낮은 혀 → 높은 혀 → 낮은 혀 | 1.10초 | 0.65초 | 2.80초 |

연속 공격 사이에는 0.45초를 둔다. 매 예고 시작 시 플레이어 방향을 고정하고 공격 범위 전체를 표시한다. 실제로 뻗은 혀만 피해를 주며 그림과 판정에 같은 좌표를 사용한다. 낮은 혀는 점프로, 높은 혀는 지상에서 피할 수 있다. 고형 혀이므로 날개 투사체 방어 대상이 아니다.

약점이 열린 동안 기본 점프로 하강하며 머리를 밟으면 HP가 1 줄고 바로 약점을 닫는다. 일반 이미지와 도형 fallback의 머리 높이를 모두 기본 점프로 공략할 수 있게 맞췄다. 실패 후 체크포인트로 돌아오면 보스 HP·단계·공격을 초기화한다. 처치 시 필드와 보스 혀를 정리하고 게이트를 생성한다.

쉬운 모드는 필드 예고 1.4배, 보스 예고 1.35배, 약점 1.3배다. 일시정지 동안 진행 시간이 흐르지 않는다. 재로드·부활·Scene 종료 시 소유한 표시와 이벤트 연결을 정리한다.

## 이미지와 재생성

이 대화의 **built-in imagegen**으로 메롱 대왕 6포즈와 왕국 배경을 생성했다. 원본과 실제 프롬프트는 [원화 설명](../assets/_source/merong/README.md), [프롬프트](../assets/_source/merong/prompts.json)에 저장했다.

- 보스: `assets/enemies/merong_king/merong_king_{idle,warning,attack,vulnerable,hurt,defeated}.png`, 각각 128×128 RGBA.
- 배경: `assets/backgrounds/bg_merong_far.png` 2048×720.
- 선택 미리보기: `assets/backgrounds/stage_preview_merong.png` 640×360.
- 포즈 검수: [메롱 대왕 6포즈](../references/merong-poses-review.png).
- 재생성: `npm run merong:assets`. 공통 배율·발 기준선·투명 여백을 유지한다.

현재 상태별 한 장의 포즈를 사용한다. 다중 프레임 팔다리 애니메이션과 전용 배경 음악은 후속 미술·음향 보강 범위이며, 현재는 기존 필드·보스 음악과 경고 효과음을 재사용한다.

빌드는 기존 큰 청크 경고를 출력하지만 오류 없이 완료했다.

기존 캐릭터 재조립의 출력 드리프트는 이번 N2에서 수정하지 않았다. 기존 미술 산출물을 유지한 상태로 전체 테스트·에셋 검증을 다시 실행했다.

## 실제 브라우저 검사

개발 페이지 `/scripts/merong-runtime.html?visualReview=level-07&debug=1&mute=1`의 실행 버튼을 사용한다. 실제 Phaser 입력·중력·충돌·겹침 이벤트를 사용하며, 보스 타격은 기본 점프 입력으로 수행한다. 체크포인트 복귀·실패 조건 재현·게이트 진입 위치는 검증 코드가 제어한다. 사용자 저장을 덮어쓰지 않도록 검증 중에는 별도의 임시 저장소로 격리하고 종료 후 원래 저장 관리자를 복구한다.

| 실제 실행 | 결과 |
|---|---|
| 실세아 · 일반 · 이미지 · 무음 | 전체 통과. 필드 자동 주행 31.0초, 별 66개, 낭떠러지 추락 0회 |
| 89% 구운 감자 · 쉬움 · 도형 fallback · 효과 감소 · 무음 | 전체 통과. 필드 자동 주행 31.6초, 별 58개, 낭떠러지 추락 0회 |
| 스테이지 선택 검수 | 7/7 메롱 왕국 카드·새 미리보기·이름·설명·선택 점 정상 표시, Space로 실제 시작 |

두 완주 검사 모두 6→7 해금, 궁전 진입 전 보스 비활성, 보스 처치 전 게이트 없음, 모든 필드 구간과 회복 체크포인트 통과, 혀의 예고·공격·휴식, 재로드 후 이전 표시 정리, 일시정지 시간 보존, 약점 외 타격 거부, 실제 점프당 HP 1 감소, 실패 후 HP·단계 초기화, 2·3단계 공격 순서, 처치 후 공격 정리, 게이트 직접 진입, 임시 클리어 기록 저장과 기존 localStorage 불변을 확인했다. 두 실행의 브라우저 오류·경고는 없었다.

일반 모드 왕국 입구·궁전 전투와 선택 카드는 화면으로 검수했다. 새 배경과 기존 나무·지형 레이어가 함께 표시되며, 보스와 별 약점·HP가 정상 표시된다.

## 남은 범위와 다음 단계

이번 검사에는 실제 게임패드 입력, 모든 캐릭터 조합의 신규 코스 실기 완주, 어린이의 체감 난이도·재미 검증을 포함하지 않았다. 두 대표 캐릭터의 실제 입력 검사와 전체 기존 자동 회귀 검사를 구분한다. 자동 주행 시간은 사람의 목표 플레이 시간 측정으로 사용하지 않는다.

다음 N3에서는 8번 테이프 도시와 테이프 대왕을 추가한다. N1의 지상 감속을 재사용하고 안전한 착지점, 감속 해제, 투척·바닥 설치·약점 공략을 연결한다.
