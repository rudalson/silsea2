# 신규 코스 N1 장치 시험 검수

2026-10-22 · 첫 구현 단계 완료

## 구현 범위

신규 스테이지 5개를 만들기 위한 공용 장치 3종을 개발용 `new-course-test` 코스에 연결했다. 메롱 왕국과 신규 대왕은 다음 N2부터 구현한다. 피아노 규칙은 원안의 해석이 남아 있어, 계획에서 추천한 자발적 5초 정지로 시험했다.

- 끈끈한 바닥: 지상 이동 속도 0.6배, 쉬운 모드 0.8배. 점프·비행·이탈 시 감속 해제. 기본 이동 tuning을 덮어쓰지 않고 기존 이동 보정과 합성한다.
- 건반 연습: 안전한 바닥에서 준비 신호 → 5초 정지 → 성공. 방향 입력·점프를 하면 다시 연습하며, 이 시험 코스에서는 실패 피해를 주지 않는다. 소리와 화면 문구·카운트다운을 함께 사용한다.
- 임시 구멍: 접근하면 1.4초 예고 후 바닥이 열리고 복구된다. 쉬운 모드는 예고 2.1초. 실제 고정 지면에 틈을 두고 충돌 발판 자체를 개폐한다. 캐릭터가 복구할 바닥과 겹쳐 있으면 닫힘을 미룬다.
- 부활·재로드·재시작 시 장치 상태 초기화, Scene 종료 시 충돌과 이벤트·표시 객체 정리.
- 시험 코스는 DEVELOPMENT_LEVELS에만 등록하며 캠페인 선택·해금·저장 기록에 포함하지 않는다. 클리어 화면도 장치 연습 완료로 안내한다.

## 직접 확인하기

개발 서버를 `npm run dev`로 실행한 뒤:

- 플레이: `http://localhost:5173/?courseTest=1&mute=1`
- 구멍부터 보기: `http://localhost:5173/?courseTest=1&section=holes&offset=64&mute=1`
- 튜닝·재로드: `http://localhost:5173/?courseTest=1&debug=1&mute=1`
- 실제 물리 검증: `http://localhost:5173/scripts/course-runtime.html?courseTest=1&debug=1&mute=1`
- 쉬운 모드·도형 표시: 위 검증 주소에 `&easy=1&fallback=1&effects=reduced&character=potato89` 추가.

검증 페이지의 **런타임 검증 실행**을 눌러 검사한다. 프레임 수를 시간으로 가정하지 않고 실제 대기 상한을 사용해 고주사율 화면에서도 5초 정지 검사를 완료할 수 있게 했다.

## 검증 결과

실제 브라우저에서 아래 두 조합 모두 장치 3종과 클리어 흐름 검증을 통과했다.

| 조합 | 일반 지면 속도 → 끈끈한 지면 속도 | 결과 |
|---|---|---|
| 실세아 / 일반 / 이미지 표시 / 무음 | 반쪽 방향 입력에서 180 → 108 | 통과 |
| 89% 구운 감자 / 쉬운 모드 / 도형·효과 감소 / 무음 | 반쪽 방향 입력에서 180 → 144 | 통과 |

확인한 흐름은 실제 지상 감속, 점프·비행 해제, 이탈 복구, 정지 위반 재도전, 5초 전 미완료, 일시정지 중 타이머 보존, 성공 문구, 구멍 앞 체크포인트, 예고 중 충돌 유지, 열림 시 충돌 제거, 추락 복귀와 구멍 복구, 데이터 재로드, 이전 자원 정리, 재시작 시 이벤트 중복 방지, 상태 초기화, 게이트 클리어와 저장 격리다. 브라우저 오류·경고 로그는 없었다.

추가로 일반 모드에서는 고정 바닥 위로 구멍 좌표를 옮긴 잘못된 데이터를 재로드했을 때 적용을 거부하고 기존 매니저와 레벨을 보존하는 검사도 통과했다. 지면 안전성 검사는 오프라인 검증기와 런타임 `LevelLoader`가 같은 함수를 사용한다. 시험 코스에서는 장치 연습 성공을 게이트의 필수 조건으로 묶지 않아 구간별 워프·개별 확인이 가능하다.

자동 검사:

- `npm test`: 기존 게임 회귀와 신규 `test-course-mechanics.js` 통과.
- `npm run validate`: 레벨·구조·에셋·통합 검사 통과. 장치의 범위·안전 구간·고정 바닥 중첩 검사를 추가했다.
- `npm run test:release`: 프로덕션 빌드 및 로컬 런타임 파일 검사 통과.

새 이미지·프레임을 만들지 않아 spritesheets 재조립은 실행하지 않았다. 장시간 soak, 실제 게임패드 기기, 나머지 캐릭터의 신규 코스 실기, 어린이 체감 난이도 검사는 이번 단계에서 수행하지 않았다. 기존 자동 캐릭터 회귀 검사는 통과했으나 이를 신규 코스 실기 완료로 대체하지 않는다.

## 다음 단계

N2에서는 `level-07` 메롱 왕국과 메롱 대왕을 구현한다. 궁전 진입, 혀 공격 예고·회피·약점, 3회 유효 타격, 실제 게이트와 다음 레벨 해금까지 연결한다. N1의 도형 장치는 최종 아트가 아니며 코스 길이·공격 수치는 각 본 스테이지에서 조정한다.
