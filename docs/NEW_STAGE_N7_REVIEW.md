# N7 신규 스테이지 통합 검수

최종 검증일: 2026-10-23

기존 6개에 신규 5개를 연결해 총 11개 캠페인으로 확장했다. 구현·자동 통합 검증과 대표 브라우저 조합을 검수했으며 실물 게임패드와 어린이 평가는 별도 항목으로 남긴다.

|---|---|---|
| 7 | 메롱 왕국·메롱 대왕 | 혀 높이·궁전 전투 · [N2](./MERONG_N2_REVIEW.md) |

| 9 | 피아노 나라·음악 대왕 | 실제 정지 문·5초·음표 · [N4](./MUSIC_N4_REVIEW.md) |

모든 신규 대왕은 HP 3, 약점 외 타격 거부, 기본 점프 머리 밟기, 공격 정리 후 약점, 부활 초기화와 처치 뒤 실제 게이트 진입을 따른다. 기존 6개 기록은 `silsea:progress:v1`에 그대로 남으며 새 저장 필드는 추가하지 않았다.

## 자동 검사

`npm test`는 기존 전체 회귀·통합한 쓰나미/수중 적·호흡 아이템과 신규 5코스·11개 최종 게이트 흐름을 통과했다. `npm run test:expansion`은 기존 기록 보존·7→11 해금/다시 읽기·다섯 대왕 이미지/도형의 기본 점프 도달성·8인 최대 충돌 크기·양 난이도 배치·11번 종료를 검사한다.

`npm run validate`는 플레이 11개·개발 5개, manifest 647키(시각 563·오디오 84), 매핑·파일·알파·기준선·레벨 정합성을 통과했다. `npm run test:release`는 프로덕션 빌드·로컬 런타임 653파일·81.59MiB·외부 URL 0개를 통과했다. 기존 큰 번들 경고는 남는다.

`npm run test:soak`는 기존 풀·파티클·Scene 정리의 60분 등가 216,000프레임 모의 검사다. 신규 보스의 60분 실기를 뜻하지 않는다. N4 원화/신호음 재생성 15파일과 N5·N6 각 12파일 SHA-256 불변을 확인했다. 캐릭터 시트는 변경하지 않아 spritesheets 재조립을 반복하지 않았고 N2에서 기록한 기존 출력 드리프트를 해결한 것으로 간주하지 않는다.

## 브라우저와 이미지

개발용 다섯 `*-runtime.html`은 실제 Phaser 입력·중력·충돌로 필드를 주행하고 재현 위치·실패·보스 접근·게이트 진입을 제어한다. 사용자 저장을 임시 저장소와 분리해 종료 시 복원한다. 각 단계 기록에 조합·결과를 남겼다. 자동 주행 시간은 사람의 목표 플레이 시간으로 사용하지 않는다.

선택 화면에서 1→11 순환·11개 선택 점·9/10/11 카드의 이름·설명·새 미리보기를 확인했다. 9번에서 Z 입력으로 피아노 나라를 시작했다. 마지막 결과 화면은 “모든 스테이지를 완료했습니다!”와 선택 버튼을 표시하며 다음 스테이지 버튼이 없다.

이번 N4~N6는 각각 실세아·일반·이미지·무음 및 89% 감자·쉬움·도형·효과 감소·무음의 두 대표 조합에서 필드부터 세 단계 대왕·게이트·임시 저장까지 완주했다. 최종 구름 검사는 두 조합 모두 빈 게이지의 기류 통과·회복·실제 밀림·반대 조작·비 방어까지 통과했고 브라우저 오류·경고가 없었다.

원화는 **built-in imagegen**으로 제작하고 최종 이미지·정확한 프롬프트·조립 메타데이터를 저장소 안에 보존했다. [메롱](../assets/_source/merong/README.md)·[테이프](../assets/_source/tape/README.md)·[음악](../assets/_source/music/README.md)·[구멍](../assets/_source/holes/README.md)·[구름](../assets/_source/cloud/README.md)의 각 폴더에 `prompts.json`이 있다. 상태별 단일 포즈이며 다중 프레임 움직임·전용 음악은 후속 미술·음향 보강 범위다.

후속 [N8](./BOSS_MOTION_N8_REVIEW.md)은 이 단일 포즈에 코드 기반 숨쉬기·준비·반동·처치 동작을 추가한다. 새 그림 프레임과 전용 음악 제작은 포함하지 않는다.

## 미실시 실기

실물 게임패드, 8명×양 난이도×신규 5코스 전체 실기, 어린이의 난이도·재미·체류 시간과 소리 청취 평가는 미실시다. 영상 음성에만 있는 추가 규칙도 전사하지 않았다. 자발적 정지·구멍 개폐·구름 돌풍은 명시한 개발 해석으로 구현했으며 자동 검사로 사람의 평가를 대신하지 않는다.
