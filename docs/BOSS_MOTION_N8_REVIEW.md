# N8 신규 5보스 동작 보강

검증일: 2026-10-23

메롱·테이프·음악·구멍·구름 대왕의 기존 상태별 원화에 코드로 움직임을 더했다. 원화 파일은 각 상태의 단일 포즈를 유지하며, 새 그림 프레임을 제작한 작업은 아니다.

| 상황 | 표시 동작 |
|---|---|
| 대기·등장·공격 사이 | 보스마다 다른 주기의 미세한 숨쉬기와 기울기 |
| 공격 예고 | 공격 방향 반대로 몸을 낮추며 준비 |
| 공격 | 짧은 전진·반동, 구멍의 좌우 리듬·음악의 지휘·구름의 부풀기 |
| 약점 | 머리와 약점 별이 안정적으로 보이는 작은 세로 움직임 |
| 피격 | 빠르게 잦아드는 반동과 기존 피격 색 동기화 |
| 처치 | 원본 보스가 비활성화된 뒤에도 900ms 동안 한 번 마무리 |

## 판정과 표시 분리

`BossMotionPresenter`는 물리 몸체 없는 Image에만 위치·크기·각도·알파를 적용한다. 원본 Sprite는 물리 월드와 애니메이션 UpdateList에 남고 DisplayList에서만 빠진다. 보스의 위치, scale, origin, 충돌 크기·오프셋, HP와 공격·약점 시간은 변경하지 않는다. 포즈 텍스처·방향·피격 색·가시성·깊이는 원본을 따른다.

추가 위치 변화는 최대 4px, 각도는 최대 2.5도이며 약점 상태에는 가로 이동·회전이 없다. 음악 대왕의 5초 정지 신호에는 추가 동작을 멈춘다. 화면 효과 `약하게`는 추가 변형 없이 기존 포즈를 표시하고, 도형 fallback과 기존 1~5 보스에는 presenter를 만들지 않는다.

게임 Scene 일시정지 동안 동작 시간이 멈춘다. 플레이어 부활 대기·변신 중에도 추가 동작 시간을 진행하지 않는다. 재로드 시 이전 Image를 제거하고 원본 Sprite의 소속을 복원하며, Scene 종료 시 Image를 정리한다.

## 재현 방법

```text
npm run test:boss-motion
http://localhost:5173/scripts/boss-motion-runtime.html?visualReview=level-07&debug=1&mute=1
http://localhost:5173/scripts/boss-motion-runtime.html?visualReview=level-07&debug=1&mute=1&easy=1&effects=reduced&character=potato89
```

검증 페이지의 **5보스 동작 검증 실행**은 보스방으로 이동해 실제 입력·중력·충돌로 기본 점프 15타격을 수행하고 게이트 진입·결과·임시 저장을 확인한다. 필드 주행을 생략하므로 새 5코스 전체 완주 검사로 해석하지 않는다. 사용자 진행 저장은 임시 저장소로 분리하고 종료 시 원래 객체를 복원한다.

재로드 직후 비활성 물리 몸체는 첫 물리 step 이전의 크기를 갖는다. 런타임 검사는 보스 활성화와 첫 공격 예고 후 크기·origin·원본 scale·각도가 모든 상태에서 유지되는지 검사한다. 구멍·구름 대왕의 기존 이동은 `Body.reset`으로 위치를 바꾸므로, 원본 위치와 몸체 상대 위치는 매 presenter 호출 직전/직후에 비교해 표시 동작이 변경하지 않는지 검사한다.

## 검사 결과

- `npm run test:boss-motion` 및 `npm test`: 통과. 신규 5종 상태·범위·방향·정지·효과 감소·원본 몸체/변환 불변·피격 색·처치 후 동작·해제 복원을 검사했다.
- `npm run test:soak`: 통과. 기존 풀·파티클·Scene 정리의 60분 등가 모의 검사이며 신규 동작의 60분 실제 플레이를 뜻하지 않는다.
- `npm run test:release`: 통과. 프로덕션 빌드와 로컬 653파일·81.59MiB·외부 URL 0개. 기존 큰 번들 경고는 유지된다.
- `npm run validate`: 통과. 플레이 11개·개발 5개, manifest 647키(시각 563·오디오 84), 매핑·알파·기준선·레벨·통합 정합성을 검사했다. 이미지·오디오는 변경하지 않아 시트·음원 재생성을 반복하지 않았다.
- 브라우저: 실세아·일반·이미지·무음 및 89% 감자·쉬움·이미지·효과 감소·무음 두 조합 모두 완료. 조합별 5보스×3회, 총 30회의 실제 기본 점프 타격·HP 중복 피해 없음·직접 게이트·결과·임시 저장을 확인했다.
- 일반 조합에서 상태 안의 표시 값 변화와 효과 감소 즉시 적용, 두 조합에서 음악 5초 정지·일시정지·5회 재로드·이전 Image 제거·처치 뒤 마무리·Scene 종료 정리·사용자 저장 보존을 확인했다. 모든 표시 호출 전후의 원본 위치/몸체와 전투 중 충돌 크기·원본 scale·origin·각도 검사를 통과했다.
- 검수 두 탭과 별도 구름 대왕 확인 화면의 브라우저 오류·경고는 0건이었다.

실물 게임패드, 전체 캐릭터 조합, 어린이의 움직임·난이도·재미 평가는 이번 검증에 포함하지 않았다. N7에 기록한 전용 음악과 다중 그림 프레임 제작도 이번 범위에 포함하지 않는다.
