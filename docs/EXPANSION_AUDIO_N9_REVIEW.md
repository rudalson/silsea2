# N9 신규 5코스 전용 음악

검증일: 2026-10-23 · 기준 커밋: `22440fb` · 구현 커밋: `cbf5bec`

무지개 릴레이 제거 이후 현재 캠페인은 10코스다. 신규 코스의 표시 순서는 6~10번이며 저장 ID `level-07`~`level-11`을 유지한다. 최근 쉼터 외형과 월드 방향 경고 변경을 포함한 소스를 기준으로 음악을 연결했다.

## 곡 구성

각 코스의 필드곡과 보스 편곡을 새로 합성했다. 같은 코스의 선율 동기를 이어가면서 보스전에서는 템포와 반주 밀도를 높인다.

| 표시 순서·코스 | 필드 키 / BPM / 길이 | 보스 키 / BPM / 길이 | 음색·리듬 |
|---|---|---|---|
| 6 메롱 왕국 | `bgm_merong` / 112 / 34.29초 | `bgm_merong_boss` / 120 / 32초 | 마림바, 장난스러운 도약 |
| 7 테이프 도시 | `bgm_tape` / 116 / 33.10초 | `bgm_tape_boss` / 124 / 30.97초 | 짧은 플럭, 규칙적인 작업장 박자 |
| 8 피아노 나라 | `bgm_piano` / 96 / 40초 | `bgm_piano_boss` / 108 / 35.56초 | 감쇠하는 건반, 신호음과 다른 구절 |
| 9 구멍 코스 | `bgm_hole` / 104 / 36.92초 | `bgm_hole_boss` / 116 / 33.10초 | 마림바·플럭, 도약하는 리듬 |
| 10 구름 코스 | `bgm_cloud` / 88 / 43.64초 | `bgm_cloud_boss` / 100 / 38.40초 | 플루트와 여유 있는 선율 |

모두 16마디 A/A′/B/A″ 구성의 22050Hz 모노 OGG다. 악보와 합성 코드는 저장소에서 관리하며 외부 음악 서비스에 의존하지 않는다. 기존 1~5코스·결과 음악과 효과음은 유지했다.

`EXPANSION_BGM`은 레벨 ID로 연결한다. 기존 구간 전환과 480ms 크로스페이드, 음량·음소거·신호음 duck을 재사용한다. BGM 박자는 피아노의 5초 정지 판정에 영향을 주지 않는다.

## 생성과 검수

```text
npm run expansion:audio
npm run test:expansion-audio
npm run test:expansion-audio -- --decode
```

선택 생성은 신규 10곡만 쓴다. 기존 오디오 84개 파일의 SHA256은 유지됐고, 신규 10곡도 재생성 전후 동일했다.

[음악 검수 페이지](http://localhost:5173/scripts/expansion-audio-runtime.html?visualReview=level-07&debug=1&mute=1)는 10곡 미리듣기와 실제 GameScene 오디오 검사를 제공한다. 검사 버튼 클릭으로 Web Audio를 열며 필드·보스 전환, 음량·음소거·정지 신호·재로드·Scene 종료 정리를 검증한다.

숨겨진 브라우저에서는 Scene 시간이 벽시계보다 느리게 진행될 수 있다. duck 복원 검사는 `scene.elapsed`와 실제 음량 변화를 기다리며 별도 90초 안전 한도를 둔다. 검증 도구의 시간 기준 보정이며 게임 타이머 변경은 아니다.

## N9 당시 확인 결과

- `npm test`, `npm run validate`, `npm run test:release` 통과. 당시 manifest 656개(시각 562·오디오 94), 런타임 662파일·81.41MiB·외부 URL 0개. 기존 번들 크기 경고는 남아 있다.
- 실제 배포 OGG 10개 디코딩 검사 통과. RMS 0.101~0.139, peak 0.372~0.447, 반복 경계 차이 최대 약 0.00362.
- 일반·실비아·이미지 조합에서 10곡의 실제 디코딩·재생·출력, 필드→보스 전환, 음량·일시정지·신호음 duck, 음소거 중 구간 변경과 해제, 재로드와 종료 정리를 확인했다.
- 쉬움·감자·도형·효과 감소 조합에서 5코스의 오디오 누락 무음 진행과 정리를 확인했다. 두 조합의 사용자 저장 기록은 유지됐고 브라우저 오류·경고는 0건이었다.
- 코스 순서 변경으로 N8 검증에서 메롱을 빠뜨리던 배열 인덱스 선택을 보스 키 선택으로 수정했다. 현재 10코스 데이터에서 신규 5보스 기본 점프 15타격, 충돌 불변, 음악 5초 정지, 게이트·재로드·임시 저장·정리를 다시 통과했다.
- 피아노 필드곡의 네이티브 미리듣기 재생·시간 진행·일시정지를 확인했다.

이 수치는 N9 당시 기록이다. 이번 N10에서 검수 문서의 손상된 한글을 UTF-8로 복구했으며 N9 검사를 새로 수행했다는 뜻은 아니다. 실물 게임패드·모든 캐릭터 조합·어린이 청취 및 장시간 체감 평가는 별도다.
