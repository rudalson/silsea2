# P3 안개 골짜기 코스 회색 상자 검토

> 상태: 2026-08-26 사용자 승인 완료
> 범위: 중간 보스를 제외한 안개 농도·시야·길 찾기·임시 게이트
> 주의: 기존 배경과 잔디 타일은 회색 상자에서만 재사용한다. 아래 화면은 최종 P3 아트가 아니다.

## 권장 수치

| 구간 | 농도 | 시야 반경 | 목적 |
|---|---:|---:|---|
| 소개 | 26% | 430px | 안전한 평지에서 안개 경계를 확인 |
| 연습 | 42% | 360px | 두 단서만 보고 짧은 pit 통과 |
| 응용 | 54% | 320px | 고저차와 이동 발판에서 길 찾기 |
| 조합 | 62% | 280px | 가장 짙은 안개와 복합 발판 |
| 회복 | 18% | 500px | 안개가 걷히며 임시 게이트 확인 |

`화면 효과 강도: 약하게`에서는 가장 짙은 조합 구간이 농도 34.1%·시야 350px가 된다. 쉬운 모드는 농도 0.82배·시야 1.15배다.

## 길 찾기 단서

- 빛 기둥: 노란 세로 실루엣과 점멸로 안전 착지점을 표시
- 바람 화살표: 청록 화살표의 좌우 이동으로 다음 진행 방향을 표시

모든 안개 영역에 두 종류를 모두 배치했다. `fallback=1`에서는 `빛 기둥`, `바람 화살표` 텍스트도 함께 표시한다.

## 구현·검증 결과

- 7,168px 코스를 소개→연습→응용→조합→회복 순서로 구성
- 체크포인트 4개, 쉬운 모드 추가 체크포인트 2개
- 세 pit의 연속 착지 간격을 최대 224px 이하로 제한
- 안개 수치와 화면 효과 옵션을 level data에서 관리
- 실제 게이트 충돌 뒤 `GameScene → ClearScene` 전환 확인
- 중간 보스 데이터·외형·패턴·보상은 추가하지 않음
- Vite 오류 오버레이와 처리되지 않은 페이지 오류 없음

- 2026-08-26 사용자가 `P3 코스 승인`으로 농도·시야 반경·두 진행 단서·코스 구성을 승인했다.
