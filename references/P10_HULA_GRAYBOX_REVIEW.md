# P10 훌라후프대왕 회색 상자 검수

> 상태: 승인 완료 — 2026-08-31 사용자 `P10 코스 승인`
> 범위: `level-04` 좌향 보스룸, 도형 행동 전략, 쓰나미 정지, 정상/fallback 전투
> 제외: 최종 캐릭터·훌라후프 아트, 전용 애니메이션, 신규 SFX

## 1. 전투 상태도

```text
intro
  → spin_guard (2.2~3.2초, 무적·접촉 피해)
  → hoop_warning (최소 0.9초, 그림자+자세+경고음)
  → hoop_volley (페이즈별 링 발사)
  → vulnerable_rest (1.8 / 1.6 / 1.4초)
      ├─ 밟기 성공 → hit → recover → spin_guard
      └─ 시간 종료 → recover → spin_guard
  → HP 0 → defeated → 게이트 1회 생성 → 자동 클리어
```

방어 중에는 보스 주변의 세 겹 회전 링이 계속 움직이고, 약점 상태에서는 모든 회전 링이 사라진 뒤 머리 위 별이 나타난다. 따라서 색상을 보지 않아도 상태를 구분할 수 있다.

## 2. 잠금 수치

| 항목 | 일반 | 쉬움 |
|---|---:|---:|
| HP / 유효 밟기 | 3 | 3 |
| 회전 방어 | 2,200~3,200ms | 동일 |
| 발사 예고 | 최소 900ms | 1.25배 |
| 약점 1/2/3페이즈 | 1,800 / 1,600 / 1,400ms | 1.35배 |
| 연속 volley 간격 | 기본 | 1.2배 |
| 같은 sequence 연속 선택 | 금지 | 금지 |

페이즈 구성은 `단일 점프 링 → 낮은 링·점프 링 교대 → 양방향 링` 순서다. 모든 무작위 선택은 레벨 seed에서 파생한 `SeededRandom`을 사용한다.

## 3. 좌향 좌표 이동표

새 보스룸 폭은 2,048px이며 기존 코스 좌표에는 동일한 값을 더했다.

| 범주 | 기존 예 | 이동 후 | 검사 |
|---|---:|---:|---|
| world width | 8,192 | 10,240 | 자동 |
| player spawn | 8,000 | 10,048 | 자동 |
| `tsunami_exit` 시작 | 0 | 2,048 | 자동 |
| 보스 전 체크포인트 | 1,024 | 3,072 | 자동 |
| 적 `e_tsunami_hill` | 6,480 | 8,528 | 자동 |
| 아이템 `tsunami_house_arc_b` | 3,376 | 5,424 | 자동 |
| 위험물 `tsunami_thorn_high` | 2,688 | 4,736 | 자동 |
| 대피처 `shelter_house_a` 시작 | 4,448 | 6,496 | 자동 |
| 카메라 cue target | 896 | 2,944 | 자동 |
| tilemap `high_shelter` | 1,536 | 3,584 | 자동 |

새 `boss_hula`는 `0~2,048`, 출구는 `x=176`, 보스는 좌향 edge offset으로 `x=560`에 배치된다. 보스 전 완전 회복 체크포인트는 boss section 밖 `x=3,072`에 있다.

## 4. 환경 연결

- `boss_hula.boss.environment.suspend: ["tsunami"]`로 보스 키와 무관하게 파도를 정지한다.
- 진입 시 경고·활성 파도와 관련 시각 객체를 즉시 정리하고 `nextWaveAt`을 무한대로 둔다.
- 보스룸에 머무는 동안 새 파도가 시작되지 않는다.
- 보스룸을 이탈하는 개발 상황에서는 respawn grace 뒤 파도를 다시 예약한다.

## 5. 검수 진입점

- 일반 회색 상자: `http://localhost:4173/?visualReview=level-04&section=boss_hula&offset=950&debug=1`
- fallback: 위 주소 끝에 `&fallback=1`
- 쉬운 모드: 위 주소 끝에 `&easy=1`
- 캐릭터 변경: `&character=silsea` 또는 `&character=potato89`

대표 화면에서 확인할 항목은 회전 중 세 겹 링, 예고 그림자, 발사 링 높이, 정지 시 머리 위 약점 별, 좌측 게이트다.

## 6. 자동 검사 결과

- `npm run test`: 통과 — 100개 선택 반복에서 회전 상한·최소 시간·동일 sequence 연속 금지 확인
- `npm run validate`: 통과 — 보스 정의·행동·phase·좌표 이동·tilemap 폭·환경 정지·오디오 호출 확인
- `npm run build`: 통과
- 방어 상태 밟기 20회는 순수 판정 함수에서 모두 거부됨을 확인
- 활성 파도를 강제로 만든 뒤 보스 정지 정책 적용 시 즉시 `idle`, wave visual 제거, 새 파도 미생성을 확인

## 7. 사용자 확인 항목

- 링 높이가 달리기/점프로 직관적으로 구분되는가
- 회전 방어와 정지 약점이 색상 없이도 구분되는가
- 약점 시간이 너무 짧거나 길지 않은가
- 좌향 진입과 보스 전 회복 지점이 자연스러운가
- 정상·fallback에서 모두 3회 밟기와 자동 클리어가 가능한가
