> 주의: 원본은 이동·이름 변경·수정하지 않았다. 현재의 평면 폴더는 아래 표로 논리 분류한다.

## 분석 방법과 한계

- 모든 이미지를 원본 해상도로 직접 확인했다.
- 팔레트는 알파 25% 미만 픽셀을 제외한 뒤 각 이미지에서 8색 median-cut 양자화로 추출했다. 비율은 초안용 근삿값이다.
- 채도·명도 범위는 HSV 픽셀 분포의 10~90 백분위다. 흰 배경, 캡처 UI, 워터마크도 원본 픽셀에 포함되므로 사람이 해석해야 한다.
- `mylittlepony1.webp`, `mario_*`, `maple_*`는 기존 상용 작품의 이미지다. 캐릭터·구도·UI·로고를 모사하지 않고 색, 선 처리, 공간 가독성 같은 추상적 특성만 참고한다.
- 이미지군 사이의 렌더링 방식이 서로 달라 2026-08-03 사용자 확인을 거쳤고, `실세아 우선 2D 셀 카툰`을 최종 화풍으로 선택했다.

## 이미지군 간 정합성 판단

| 이미지군 | 렌더링 | 강점 | 충돌 지점 |
|---|---|---|---|
| 실세아 2장 | 색상 외곽선의 3톤 셀 카툰 | 원안 캐릭터 외형과 실제 달리기 포즈 | 배경 참고 이미지보다 단순하고 저채도 |
| 포니 1장 | 1~2톤 평면 벡터 | 변신 부속물 판독성 | 실세아보다 머리가 크고 형태가 단순함 |
| 마리오 3장 | 3D 카툰/게임 캡처 | 높은 가독성, 보상 동선, 축제감 | 선화가 없고 그라디언트·재질광이 강함 |
| 메이플 2장 | 질감 많은 회화적 2D | 다층 횡스크롤 공간과 숲 분위기 | 실세아보다 색·명암·장식 밀도가 높음 |

네 이미지군은 그대로 혼합하면 하나의 화풍으로 보이지 않는다. 검토한 선택지는 다음과 같다.

1. **실세아 우선 2D 셀 카툰**: 실세아 2장을 최종 렌더링 기준으로 잠그고, 포니·마리오·메이플은 변신 문법·레벨 가독성·원근 구조만 참고한다.
2. **메이플 우선 회화적 2D**: 배경 질감과 입체 명암을 우선하고 실세아도 그 화풍으로 다시 앵커링한다.
3. **평면 벡터 카툰**: 포니 계열의 단순한 1~2톤 표현을 우선하고 실세아와 배경을 함께 단순화한다.

## 흑백 대비 검토

Phase 0에서는 실제 생성 에셋이 없으므로 픽셀 대비 시트를 첨부할 수 없다. 대신 승인 후 제작할 시트의 기준을 잠근다.

- 아군: 말형/감자형의 둥근 외곽과 위로 열린 자세.
- 위험: 가시, 부리, 번개, 뾰족한 호박 꼭지처럼 바깥으로 향하는 삼각형.
- 수집: 별, 원, 둥근 뿔·날개 토큰처럼 닫히고 둥근 형태.
- 약점: 머리 위 별빛과 점멸 링을 함께 사용해 색만으로 알리지 않음.
- 검증 시 전 에셋을 동일 크기 흑백 실루엣으로 배열하고 25% 축소 상태에서도 역할을 구분할 수 있어야 한다.
