## 권장 결론

C2는 **결과 화면 업적 스티커**로 진행하는 것을 권장한다. 사진 모드는 플레이 중 상태 정지, HUD 분리, 캔버스 캡처, 브라우저 다운로드와 실패 처리가 함께 필요하다. 반면 스티커는 이미 `ClearScene`에 전달되는 `achieved`와 `clearReview`를 사용해 결과 화면 내부에만 격리할 수 있다.

기존 선택 목표 카드는 “무엇을 달성했는지” 글로 설명한다. 새 스티커는 그 정보를 대신하지 않고 승리 캐릭터 주변을 장식하는 즉각적인 시각 보상만 담당한다.

## 기능 계약

| 항목 | 잠금 후보 |
|---|---|
| 표시 시점 | `ClearScene` 진입 뒤에만 표시 |
| 기본 스티커 | 무지개 클리어 1개 |
| 업적 스티커 | 별 수집가, 비밀 탐험가, 번개 질주, 완벽한 모험 |
| 최대 수 | 기본 1개 + 서로 다른 달성 목표 4개 = 5개 |
| 배치 | 승리 초상 주변 고정 슬롯 5곳, 텍스트·카드·버튼 금지 영역 회피 |
| 조작 | 자동 배치, 신규 키·선택·드래그 없음 |
| 저장 | 세션 한정, `ProgressManager` 변경 없음 |
| 외부 출력 | 이미지 다운로드·클립보드·네트워크 전송 없음 |
| 효과 | 일반: 짧은 1회 팝, reduced: 100ms 이내 페이드 |
| 소리 | 기존 `sfx_ui_select` 저음량, 최대 3회 |
| fallback | 같은 슬롯에 문자 없는 코드 도형 표시 |
| 접근성 | 결과 요약 끝에 표시된 스티커 이름 추가 |

## 스티커 시각 언어

| 스티커 | 실루엣 | 표시 조건 |
|---|---|---|
| 무지개 클리어 | 둥근 무지개 아치와 작은 별 | 항상 |
| 별 수집가 | 굵은 5각 별과 작은 반짝임 | `collect_stars` |
| 비밀 탐험가 | 열쇠구멍이 있는 둥근 배지 | `find_secrets` |
| 번개 질주 | 날개가 달린 둥근 시계 | `clear_time` |
| 완벽한 모험 | 하트가 들어간 방패 | `no_damage` |

문자, 숫자, 언어별 글리프와 플랫폼마다 모양이 달라지는 이모지는 사용하지 않는다. 흑백 25% 축소에서도 외곽 실루엣만으로 구분되어야 한다.

## 제외 범위

- 플레이 중 사진 모드와 일시정지 메뉴
- HUD 숨김, 카메라 이동·줌, 화면 필터
- PNG/JPEG 저장, 공유, 클립보드 복사
- 자유 드래그·회전·확대와 스티커 편집기
- 스티커 컬렉션·앨범·영구 해금 저장
- 점수·목표 보상·스테이지 진행도 변경
- 신규 BGM·SFX와 결과 화면 밖 표시

## 안전·접근성 기준

- 스티커가 없어도 기존 결과 화면의 모든 정보와 버튼이 완전해야 한다.
- 장식은 캐릭터 얼굴·몸통, 레벨명, 기록, 점수, 목표 카드, 다음 단계 안내를 가리지 않는다.
- `effects=reduced`에서 위치·회전·스케일 애니메이션을 사용하지 않는다.
- 음소거에서는 SFX 호출이 시각 상태를 막지 않는다.
- 알 수 없는 목표나 중복 목표는 조용히 제거하며 오류를 만들지 않는다.
- 표시된 스티커 이름은 `#game-status`의 기존 결과 요약 뒤에만 덧붙인다.
