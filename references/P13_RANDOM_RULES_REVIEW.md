# P13 랜덤대왕 시작 규칙 검토

> 상태: 사용자 승인 완료 — 2026-09-02 사용자 `P13 규칙 승인`
> 범위: 랜덤 결과 덱, 코스 재도전, 점수 증감, 강제 재도전 시간, 메롱 피해 뒤 처리
> 제외: 회색 상자 수치·배치의 최종 승인, 흑백/컬러 아트, 전용 효과음

## 영상에서 확정된 원칙

- 랜덤대왕은 `코스 재도전`, `점수 증가`, `점수 감소`, `직접 전투` 가운데 하나를 고른다.
- 비전투 결과가 계속 나와도 결국 직접 전투가 시작되어야 한다.
- 직접 전투에서는 위치와 공격을 무작위로 바꾸며, 하늘에서 메롱 공격을 사용할 수 있다.
- 메롱에 맞으면 HP가 1 감소한다.
- 전사에서 확정할 수 없는 자동 반격, 재수집, 시간 처리, 점수량은 아래 권장안으로 사용자 승인을 받는다.

## 승인 요청 권장안

| 결정 | 권장값 | 이유 |
|---|---|---|
| 메롱 직후 자동 반격 | 없음 | 다른 공격과 똑같이 회피 또는 피격 뒤 약점 시간이 열리고, 플레이어가 직접 밟아야 전투 규칙이 일관된다. |
| 강제 코스 재도전의 수집물 | 이미 획득한 것은 되살아나지 않음 | 별·점수·objective의 무한 파밍과 중복 완료를 막는다. 아직 획득하지 않은 기존 수집물은 그대로 남는다. |
| 선택 목표 `clear_time` | 강제 재도전 구간 시간만 제외 | 랜덤 결과 때문에 선택 목표를 잃는 불공정을 막되, 일반 진행과 보스 대기·전투 시간은 계속 센다. |
| 점수 증가·감소량 | `+100` / `-100` | 기존 큰 퍼센트 토큰 1개와 같은 단위라 이해하기 쉽고, 증가·감소가 대칭이다. 감소는 0에서 멈추며 콤보를 초기화한다. |

## 결과 덱과 종료 보장

결과 키는 데이터에 `replay_section`, `score_plus`, `score_minus`, `start_battle`로 기록한다. 각 추첨은 같은 seed에서 완전히 같은 결과를 내야 한다.

- 같은 결과는 연속으로 나오지 않는다.
- `replay_section`이 다시 뽑혀도 직전 재도전 코스와 같은 코스는 고르지 않는다.
- 비전투 결과는 최대 3회까지만 허용하고, 다음 추첨은 반드시 `start_battle`로 바꾼다.
- `start_battle`이 나오면 결과 덱을 종료하고 직접 전투 상태로 한 번만 전환한다.
- 결과 표시 중에는 플레이어 이동과 피해 판정을 잠시 막고, 표시가 끝난 뒤 점수 처리 또는 안전 재진입을 수행한다.
- 모든 결과 추첨, 선택 코스, 강제 전투 전환은 seed와 함께 플레이테스트 이벤트에 기록한다.

## 안전한 코스 재도전

랜덤 좌표를 만들지 않고 `level-02`의 검증된 안전 바닥만 목적지로 사용한다. 회색 상자 구현 때 실제 충돌 바닥과 카메라 경계를 다시 검사해 아래 앵커를 데이터로 잠근다.

| 코스 | 권장 재진입 앵커 | 재진입 처리 |
|---|---:|---|
| 달빛 길 | 시작 안전 바닥 `x=256` 부근 | 월드 왼쪽 경계와 거리를 두고 카메라·적 활성 범위를 처음 코스 상태로 재계산 |
| 빛나는 숲관 | `cp_moonroot`, `x=1664` 부근 | 체크포인트를 덮어쓰지 않고 안전 유예만 적용 |
| 속삭이는 틈 | `cp_fireflies`, `x=3712` 부근 | 이동 발판·레이저를 현재 스테이지 상태에 맞춰 재동기화 |
| 별나무 | `cp_star_tree`, `x=5120` 부근 | 완료 objective·수집 상태를 유지하고 출구 방향으로 재진행 |

- 목적지는 직전 재도전 코스를 제외한 후보 중 seed로 선택한다.
- 재진입 직후 일반 1.0초, 쉬움 1.5초 동안 환경·적 접촉 피해를 막는다. 이 유예는 공격용 무적이나 알리콘 시간 연장으로 쓰지 않는다.
- 캐릭터 HP, 현재 변신과 비행 게이지, 획득한 수집물, 완료 objective, 해제한 레이저 스위치, 적 처치 상태는 유지한다.
- 카메라와 환경 활성 범위만 새 위치에 맞춰 즉시 재계산한다. 이미 처치한 적이나 수집한 아이템을 다시 만든 것으로 취급하지 않는다.
- 재도전 코스를 지나 다시 랜덤대왕 대기실에 들어오면 다음 결과를 뽑는다.

## 점수 처리 예시

| 추첨 전 점수 | `score_plus` | `score_minus` |
|---:|---:|---:|
| 0 | 100 | 0 |
| 80 | 180 | 0 |
| 250 | 350 | 150 |

- HUD에는 `랜덤 보너스 +100` 또는 `랜덤 페널티 -100`을 표시한다.
- 감소는 점수를 음수로 만들지 않으며 감소량이 0이어도 콤보는 초기화한다.
- 결과 처리 한 번당 점수 변경 이벤트도 한 번만 기록한다.

## `clear_time` 계산

전체 플레이 시간은 기존처럼 계속 누적하고 결과 화면과 플레이테스트 기록에 보존한다. 선택 목표 판정에만 아래 값을 사용한다.

`선택 목표 시간 = 전체 플레이 시간 - 강제 재도전 구간 누적 시간`

- 강제 재도전 시간은 워프가 끝난 시점부터 랜덤대왕 대기실에 다시 진입한 시점까지다.
- 점수 결과 표시, 랜덤대왕 대기, 직접 전투는 제외하지 않는다.
- 재도전 중 사망해 체크포인트에서 다시 시작해도 대기실로 돌아올 때까지 같은 강제 재도전 시간에 포함한다.
- 디버그/플레이테스트에는 전체 시간, 제외 시간, 선택 목표 시간을 모두 남긴다.

## 메롱과 직접 전투

- 메롱은 고유한 하늘 예고 뒤 플레이어 위치를 덮는 공격이며, 맞으면 기존 피해 처리로 HP 1을 잃는다.
- 기존 피격 무적 시간과 알리콘 무적을 존중하므로 같은 실행에서 피해가 중복되지 않는다.
- 메롱 성공 여부와 관계없이 공격 종료 뒤 약점 시간이 한 번 열린다.
- 자동 반격이나 자동 보스 피해는 없다. 플레이어가 약점 시간에 직접 밟아야 보스 HP가 감소한다.
- 지상 투사체, 상단 투사체, 위치 이동 뒤 투척, 하늘 메롱은 같은 공격을 2회 연속 고르지 않는다.
- 각 phase에서 모든 공격을 한 번씩 볼 수 있는 보정 덱을 사용하며, 모든 공격 뒤 약점 시간을 보장한다.
