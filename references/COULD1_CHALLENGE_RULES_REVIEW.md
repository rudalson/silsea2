## 한 줄 정의

정규 5개 스테이지를 통과한 뒤 열리는 6번째 스테이지 **무지개 이어달리기**는 기존 이동·변신·발판·장애물을 5,120px 안에서 다시 시험하는 보스 없는 3분 챌린지다.

## 이번 승인에서 잠글 내용

1. `level-06`, 오른쪽 진행, 5,120×768, 일반 150~210초 목표로 만든다.
2. 기본 상태로 지상 안전 경로를 완주할 수 있고 유니콘·날개·알리콘은 별 보상 지름길만 연다.
3. 시작 → 유니콘 돌파 → 공중 발판 → 복합 시험 → 무위험 회복/게이트의 5구간으로 구성한다.
4. 보스·비밀 공간·새 핵심 기믹은 추가하지 않는다.
5. 기존 밝은 들판 에셋과 오디오를 재사용하고, 코스 승인 뒤 선택 카드 미리보기만 별도로 제작한다.
6. 필수 목표는 게이트 도달, 선택 목표는 별 30개·180초·무피해다.
7. 적 4, 호박 5, 낭떠러지 2, 이동 발판 2, 붕괴 발판 2를 각각 최대치로 둔다.
8. 체크포인트는 3개, 쉬운 모드는 추가 체크포인트 1개와 기존 완화 규칙을 적용한다.
