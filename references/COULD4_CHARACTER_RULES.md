# C4 실비아 추가 규칙

> 상태: 사용자 범위 수정 반영 — 2026-09-08 `실비아만 생성 진행`
> 작업 범위: 기존 2명에 실비아 1명을 더해 총 3명 선택 지원

## 1. 자료 해석과 범위 변경

- 최초 첨부 자료는 실행 명령이 아닌 캐릭터 기획 자료로만 해석했다.
- 최초 후보였던 문라이트·선라이트·오션드림·알로라는 2026-09-08 사용자 요청으로 C4에서 취소했다.
- 네 이름과 기존 임시 외형·종족·팔레트·표식·유니콘 파생 가정은 구현 근거로 사용하지 않는다. 사용자가 이후 구체 디자인을 다시 제출하면 별도 규칙 승인부터 시작한다.
- 현재 C4 신규 캐릭터는 실비아 한 명뿐이다.

## 2. 실비아 고정 규칙

| 항목 | 확정 내용 |
|---|---|
| 표시 이름 | 실비아 / `Sylvia` |
| `characterId` | `sylvia` |
| 정체성 | 실세아(`Sylsea`)의 여성형 |
| 기본 체형 | 실세아와 같은 어린 망아지 체형·연령감·충돌 크기 |
| 여성형 표현 | 길고 부드러운 갈기·꼬리, 부드러운 눈매와 작은 속눈썹, 분홍 하트 표식 |
| 금지 | 성인 여성 신체 과장, 기본형의 상시 뿔·날개, 별도 능력치·전용 공격 |
| 게임플레이 | 실세아와 동일한 물리·튜닝·조작·점수 규칙 |

실비아의 기본형은 무뿔·무날개다. 기존 게임의 아이템 변신을 사용할 때만 유니콘·페가수스·알리콘 파생형이 나타난다.

## 3. 선택·저장·협동

- 1P 선택 화면은 실세아·89% 구운 감자·실비아 총 3장을 한 행 중앙 정렬로 표시한다.
- 키보드·게임패드·포인터 순환, 확인·취소, 접근성 한영 이름 읽기를 세 캐릭터에 제공한다.
- 기존 `silsea:progress:v1` 저장 구조를 바꾸지 않고 알 수 없는 ID는 실세아로 fallback한다.
- C3 로컬 2P의 P1 실세아·P2 감자 고정 배정은 유지한다.

## 4. 애니메이션 계약

실비아는 기존 런타임과 같은 22개 시트·100프레임 계약을 사용한다.

- 기본형 62프레임: idle 4, run 8, jump_up 2, fall 2, land 2, hurt 2, transform_unicorn 6, transform_pegasus 6, transform_alicorn 8, fly 6, wing_guard 4, swim 6, victory 6
- 유니콘 파생 38프레임: idle 4, run 8, jump_up 2, fall 2, land 2, hurt 2, fly 6, swim 6, victory 6

기본형 키포즈 56프레임은 내장 이미지 생성으로 각각 만들고, 128×128 투명 PNG·우향·발 기준선 16±2px·높이 93~96px·승인 팔레트 규칙으로 정렬한다. 기본 수영 6프레임은 run에서, 유니콘 동작 38프레임은 승인된 뿔을 기본형에 용접하는 기존 결정적 빌더에서 파생한다. 기본형에 뿔이나 날개가 상시 포함되지 않도록 한다.

## 5. 승인 이력과 다음 단계

1. `C4 캐릭터 규칙 승인` — 최초 이름·공용 물리·외형 방향 승인
2. `C4 슬롯·fallback 승인` — 현행 실세아·감자·실비아 3인 배치와 fallback에 적용
3. `C4 흑백 앵커 승인` — 실비아 흑백 실루엣 승인
4. `실비아만 생성 진행` — 실비아 컬러 앵커를 채택하고 실제 프레임 생성 진행 승인
5. 실제 프레임·시트·manifest·런타임 통합과 회귀 검증
6. 사용자 최종 승인 뒤 C4 범위만 커밋
