# C3 로컬 2P 프로토타입 — 규칙 검토

> 상태: 사용자 규칙 승인 완료 — 2026-09-07 `C3 규칙 승인`
> 작성일: 2026-09-07
> 진입 원칙: 정규 1P와 저장 데이터에서 격리된 개발 전용 프로토타입

## 1. 목표와 제외 범위

C3의 목표는 한 화면에서 P1 키보드와 P2 게임패드가 기존 두 캐릭터를 함께 조작할 수 있는지를 검증하는 것이다. 완성된 정규 2P 모드가 아니라 입력 분리, 상태 소유권, 카메라, 재합류와 전투 타깃 규칙을 실제 플레이 가능한 회색상자로 증명한다.

포함 범위:

- P1 키보드 + P2 첫 번째 게임패드 한 세트
- 실세아 P1 + 89% 구운 감자 P2 고정 배정
- 한 화면 카메라와 거리 제한·자동 재합류
- 공유 진행과 개별 체력·변신
- 일반 적, 시험용 보스, 체크포인트와 동시 게이트
- 코드 도형 HUD와 접근성 상태

제외 범위:

- 온라인, 분할 화면, 3인 이상, 두 키보드, 입력 장치 재배정
- 캐릭터 선택 UI와 동일 캐릭터 중복 선택
- 새 캐릭터·적·보스·배경 아트와 신규 음악
- 정규 레벨 해금, 최고 점수, 설정 또는 플레이테스트 기록 저장
- 정규 스테이지와 `GameScene`을 2P로 전환하는 작업

## 2. 입력 규칙

| 역할 | 이동 | 점프/확인 | 특수 행동 | 일시정지 |
|---|---|---|---|---|
| P1 실세아 | 방향키 또는 WASD | Space 또는 Z | Shift 또는 X | Esc |
| P2 감자 | pad 0 스틱 또는 D-pad | A / button 0 | X / button 2 | Start / button 9 |

- `CoopInputManager`가 두 입력을 별도 이전 상태와 함께 샘플링한다. 한 플레이어의 누름 edge가 다른 플레이어에게 전달되지 않는다.
- 게임패드가 없으면 P2는 `게임패드 연결 대기` 상태로 멈추고 P1은 계속 움직일 수 있다.
- 연결이 끊긴 P2는 피해와 낭떠러지 판정에서 제외하고, 재연결하면 공유 체크포인트에서 복귀한다.
- 브라우저 자동 검수는 고정 상태 진입점만 사용한다. 실제 gamepad 입력 완료 여부를 자동 입력으로 대체하지 않는다.

## 3. 상태 소유권

| 상태 | 소유권 | 규칙 |
|---|---|---|
| HP·피격 무적 | 개별 | 각 3 HP, 맞은 플레이어만 감소·점멸·밀려남 |
| 변신·비행·가드 | 개별 | 아이템을 얻은 플레이어에게만 적용 |
| 체크포인트 | 공유 | 어느 플레이어든 활성화, 부활 위치만 좌우 분리 |
| 별·목표·비밀 | 공유 | 최초 접촉 1회만 집계 |
| 점수·콤보 | 공유 | 세션 점수 하나, 부활 감점은 사건당 한 번 |
| 환경 스위치 | 공유 | 어느 플레이어든 조작하면 월드에 한 번 반영 |
| 보스 HP·격파 | 공유 | 두 플레이어의 유효 공격을 같은 HP에 반영 |
| 완료·해금 | 세션 한정 | 결과를 보여도 영구 저장하지 않음 |

플레이어끼리는 물리 충돌하지 않고 서로를 밀거나 밟을 수 없다. 친선 피해도 없다.

## 4. 부활과 재합류

### HP 0 또는 추락

- 해당 플레이어만 0.7초 동안 비활성 반투명 상태가 된다.
- 공유 체크포인트를 기준으로 P1은 -48px, P2는 +48px 위치에 최대 HP로 돌아온다.
- 복귀 후 1.2초 동안 해당 플레이어만 무적이다.
- 다른 플레이어의 이동, 변신, 체력과 입력은 중단하지 않는다.
- 두 플레이어가 동시에 쓰러져도 같은 체크포인트에 순서대로 복귀하며 게임 오버 화면은 만들지 않는다.

### 화면 이탈

- 카메라는 두 활성 플레이어의 중점을 따라가되 월드와 보스 아레나 경계를 벗어나지 않는다.
- 수평 거리 820px 또는 수직 거리 360px를 넘으면 후행 플레이어에게 번호와 화살표 경고를 표시한다.
- 수평 1000px 또는 수직 480px 초과가 1초 지속되면 진행 방향에서 뒤처진 플레이어를 재합류시킨다.
- 재합류 지점은 선행 플레이어 뒤 96px에 가까운 안전 지점이며, 플레이어별 좌우 오프셋과 1.2초 무적을 적용한다.
- 진행도가 같은 경우 카메라 중심에서 더 먼 플레이어를 후행으로 보고, 완전히 같으면 P2를 이동시켜 결과를 결정적으로 유지한다.

## 5. 아이템과 변신

- 별과 일반 점수 수집물은 먼저 닿은 한 번만 제거하며 공유 목표와 점수에 반영한다.
- 뿔·날개·알리콘은 먼저 닿은 플레이어가 소유하고 그 플레이어의 `TransformationManager`만 변경한다.
- 자석 효과는 해당 플레이어가 끌어당기지만 실제 획득은 최초 접촉자 기준이다.
- 비행 에너지, 가드 cooldown, 알리콘 제한 시간은 플레이어별로 독립한다.
- 한 플레이어의 변신 연출은 다른 플레이어의 물리 이동을 잠그지 않는다. 카메라 확대 대신 해당 플레이어 주변의 축소된 강조 효과만 사용한다.

## 6. 적과 보스 타깃

- 적은 공격 결정 시점에 가장 가까운 활성 플레이어를 선택한다. 거리가 같으면 P1을 선택한다.
- 보스는 텔레그래프 시작 시 아레나 안의 가장 가까운 활성 플레이어를 타깃으로 잠근다.
- 타깃은 공격 하나가 끝날 때까지 바뀌지 않는다. 타깃이 비활성·부활 중이거나 아레나 밖이면 즉시 다른 유효 플레이어를 선택한다.
- 조준 투사체는 잠금 당시 위치 또는 기존 패턴이 요구하는 추적 규칙을 사용하며 공격 도중 더 가까워진 플레이어로 갑자기 꺾이지 않는다.
- 어느 플레이어든 유효 약점 공격으로 공유 보스 HP를 줄일 수 있다. 같은 물리 프레임의 중복 판정은 공격자별 cooldown과 보스 피격 잠금으로 한 번만 처리한다.
- 접촉·투사체 피해는 충돌한 플레이어의 개별 체력으로 전달한다.

## 7. 게이트와 결과

- 체크포인트, 비밀, 목표와 보스 격파는 두 플레이어가 공유한다.
- 게이트는 두 활성 플레이어가 동시에 영역 안에 있을 때만 통과한다.
- P2가 연결 대기 또는 부활 중이면 게이트를 완료할 수 없고 상태 문구로 필요한 행동을 알린다.
- 결과 화면에는 두 캐릭터와 공유 세션 결과만 표시한다.
- `progressManager.completeLevel`, 로컬 저장, 다음 정규 스테이지 해금은 호출하지 않는다. 결과에서 다시 시험하거나 메뉴로 돌아간다.

## 8. HUD·접근성

- P1은 원형 `1`, P2는 마름모 `2` 표식을 캐릭터 위와 HUD에 반복해 색상에 의존하지 않는다.
- 플레이어별 HP·현재 형태·비행 게이지를 좌우에 분리하고 공유 점수·목표는 중앙에 한 번 표시한다.
- 게임패드 대기·재연결, 거리 경고, 재합류, 부활, 아이템 획득자와 보스 타깃 변경을 `P1 실세아`, `P2 감자` 이름으로 읽는다.
- reduced 효과에서는 카메라 확대·흔들림 없이 100ms 이하 페이드만 사용한다. mute와 fallback에서도 동일 정보가 남는다.

## 9. 기술 경계와 구현 순서

현재 `InputManager`는 키보드와 pad 0을 하나의 입력으로 병합하고, `GameScene`, `HealthManager`, `TransformationManager`, 환경·적·보스 매니저는 단일 `player`를 직접 참조한다. 따라서 다음 순서로 진행한다.

1. 거리·타깃·소유권·게이트 판정을 순수 데이터와 함수로 먼저 작성한다.
2. 기존 1P 입력을 바꾸지 않는 별도 2P 입력 샘플러를 추가한다.
3. `c3-coop-test`와 `CoopPrototypeScene`에서 두 `Player`와 최소 지형을 띄운다.
4. 공유 세션 상태와 플레이어별 체력·변신 어댑터를 연결한다.
5. 한 화면 카메라, 경고와 안전 재합류를 연결한다.
6. 적·시험 보스·동시 게이트를 순서대로 연결한다.
7. 2P HUD·접근성 상태와 reduced/mute/fallback을 검증한다.
8. 자동 검사 후 실제 키보드+게임패드 완주를 별도로 기록한다.

이 단계에서는 정규 `GameScene`의 다중 플레이어 리팩터링을 선행하지 않는다. 프로토타입 최종 승인 뒤 재사용 가치가 확인된 경계만 후속 작업 후보로 남긴다.

## 10. 승인 기준

다음 사항을 함께 승인한다.

- 키보드 P1 + pad 0 P2, 캐릭터 고정 배정
- 공유 진행과 개별 HP·변신의 경계
- 거리 임계값과 자동 재합류
- 최초 접촉 아이템 소유권
- 결정적 적·보스 타깃과 두 명 동시 게이트
- 저장 없는 개발 전용 장면 및 제외 범위
