## 구현 결과

- `무지개 클리어`는 항상 표시한다.
- 선택 목표는 `collect_stars` → `find_secrets` → `clear_time` → `no_damage`의 고정 순서로 추가한다.
- 중복·알 수 없는 값은 무시하고 최대 5개까지만 표시한다.
- 스티커는 문자나 이모지 없이 코드 도형으로 그린다.
- 새 조작·저장·다운로드·네트워크 경로는 없다.

## 등장 효과와 접근성

- 일반 효과: 아래 12px·72% 크기에서 260ms 동안 한 번만 도장처럼 등장한다.
- 약한 효과: 최종 위치·각도·100% 크기를 처음부터 유지하고 100ms 투명도 전환만 사용한다.
- 기존 `sfx_ui_select`를 볼륨 `0.28`로 첫 3개에만 호출한다.
- `#game-status`의 기존 레벨·캐릭터·기록·점수·목표 요약 뒤에 실제 표시된 스티커 이름을 순서대로 덧붙인다.

## 재현 주소

개발 서버 기준 주소다. 모든 조합은 기존 `clearReview` 진입점만 사용한다.

- 기본 1개: `http://127.0.0.1:5173/?clearReview=level-01&achieved=&elapsed=555&score=900`
- 목표 1개·총 2개: `http://127.0.0.1:5173/?clearReview=level-01&achieved=collect_stars&elapsed=555&score=900`
- 목표 3개·총 4개: `http://127.0.0.1:5173/?clearReview=level-01&achieved=collect_stars,find_secrets,clear_time&elapsed=555&score=900`
- 목표 4개·총 5개: `http://127.0.0.1:5173/?clearReview=level-01&achieved=collect_stars,find_secrets,clear_time,no_damage&elapsed=555&score=900`
- 약한 효과+fallback: 위 목표 3개 주소 끝에 `&effects=reduced&fallback=1` 추가
