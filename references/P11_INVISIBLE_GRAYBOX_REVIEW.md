# P11 투명대왕 회색 상자 검수

> 상태: 승인 완료 — 2026-09-01 사용자 `P11 코스 승인`
> 범위: `level-03` 우측 보스룸, Seed 위치 선택, 빛 공개·기억 타격·실패 공격, 일반·효과 약하게·음소거
> 제외: 최종 투명대왕 아트, 전용 애니메이션, 신규 SFX

## 1. 전투 상태도

```text
hidden_relocate (숨은 채 다음 위치 선택·이동)
  → light_warning (최소 0.9초, 빛기둥+위치 고리+경고음)
  → revealed (1.2초, 원형 실루엣 공개·공격 불가)
  → hidden_memory_window (1.8 / 1.6 / 1.4초, 같은 위치에서만 밟기 가능)
      ├─ 밟기 성공 → hit → recover → hidden_relocate
      └─ 시간 종료 → miss_attack (0.9초 십자 범위 예고) → recover
  → HP 0 → defeated → 게이트 1회 생성 → 자동 클리어
```

보스의 물리 몸체는 기억 타격 창에만 활성화된다. 공개가 끝난 뒤에는 위치를 옮기지 않으며, 직전 공개 위치의 118×118 몸체를 위에서 밟았을 때만 HP가 감소한다.

## 2. 잠금 수치

| 항목 | 일반 | 쉬움 |
|---|---:|---:|
| HP / 유효 밟기 | 3 | 3 |
| 빛 예고 | 최소 900ms | 1.25배 |
| 완전 공개 | 1,200ms | 동일 |
| 기억 창 1/2/3페이즈 | 1,800 / 1,600 / 1,400ms | 1.35배 |
| 실패 공격 예고 | 최소 900ms | 1.25배 |
| 같은 위치 연속 선택 | 금지 | 금지 |
| 최근 2개 위치 가중치 | 1 | 1 |
| 그 외 위치 가중치 | 3 | 3 |

모든 무작위 위치 선택은 레벨 Seed에서 파생한 `SeededRandom`만 사용한다. 영상에서 제안에 그친 뿔 발사 공격은 이번 범위에 넣지 않았다.

## 3. 보스룸과 위치 앵커

기존 `level-03`의 `0~7,168` 좌표와 안개 밀도는 그대로 두고 오른쪽에 2,048px을 추가했다.

| 항목 | 값 |
|---|---:|
| 기존 코스 끝 / 보스룸 시작 | x=7,168 |
| 보스룸 끝 / world width | x=9,216 |
| 보스 직전 완전 회복 | x=7,040 |
| 새 출구 | x=9,040 |
| 보스룸 안개 | 밀도 0.24, 가시 반경 460px |

| 앵커 | 좌표 | 접근 |
|---|---:|---|
| `left_ground` | 7,520 / 576 | 평지 점프 |
| `left_air` | 7,856 / 448 | x=7,744~7,968, y=496 기억 발판 |
| `center_ground` | 8,192 / 576 | 평지 점프 |

공중 위치 두 곳에는 기본 점프 상승량으로 보스 머리 위를 확실히 넘을 수 있는 높이 80px 발판을 배치했다. 변신 능력은 필요하지 않다.

## 4. 위치 전달과 접근성

- 모든 후보 위치에는 크기가 다른 바닥 눈금과 원형 고리가 항상 있어 색을 보지 않아도 후보를 구분할 수 있다.
- `light_warning`은 선택 위치 위의 세로 빛기둥과 커지는 고리를 함께 보여 준다.
- `revealed`는 왕관·눈·입이 있는 원형 실루엣을 1.2초 동안 완전히 보여 준다.
- 공개가 끝나면 빛과 실루엣이 함께 사라져 기억 규칙을 유지한다.
- 실패 시 빨간색 외에도 큰 원과 흰색 십자선이 0.9초 동안 커져 위험 범위를 전달한다.
- 화면 효과 `약하게`는 환경 안개만 낮추며 보스 빛·실루엣·십자선은 유지한다.
- 음소거에서는 빛기둥·실루엣·위치 고리의 시각 단서만으로 진행할 수 있다.
- 접근성 상태 문구는 빛 예고, 공개, 기억 타격, 실패 공격을 각각 설명한다.

## 5. 고정 상태 검수 진입점

- 실제 반복: `http://localhost:5173/?visualReview=level-03&section=boss_invisible&offset=1120&debug=1`
- 빛 예고: 위 주소에 `&invisible=warning`
- 완전 공개: 위 주소에 `&invisible=revealed`
- 숨은 기억 창: 위 주소에 `&invisible=memory`
- 실패 공격: 위 주소에 `&invisible=miss`
- 효과 약하게·음소거: 위 주소에 `&effects=reduced&mute=1`
- 쉬운 모드: 위 주소에 `&easy=1`
- 도형·무음 fallback: 위 주소에 `&fallback=1`
- 캐릭터 변경: `&character=silsea` 또는 `&character=potato89`

고정 상태 주소는 타이머를 멈추므로 빛 방향, 공개 실루엣, 완전 투명 상태, 실패 공격 범위를 각각 따로 비교할 수 있다.

## 6. 검증 결과

- `npm run test`: 통과 — 100개 Seed × 24회 선택에서 같은 위치 연속 및 3연속 선택 없음
- `npm run validate`: 통과 — 보스 정의·행동 등록·phase·tilemap 폭·목표·체크포인트·비콘 수 확인
- `npm run build`: 통과
- 다섯 앵커가 arena 안이고 보스룸 바닥 위이며, 공중 앵커 두 곳에 기본 점프용 발판이 있음을 자동 확인
- 일반 모드 공개 상태와 `effects=reduced&mute=1` 실패 공격 상태를 1280×720 런타임에서 확인
- 기존 짙은 안개 조합 구간과 회복 구간의 좌표·밀도는 변경하지 않음

## 7. 사용자 확인 항목

- 빛 예고 0.9초와 완전 공개 1.2초가 위치를 파악하기에 적당한가
- 다섯 후보 중 공중 위치도 기본 점프로 자연스럽게 밟을 수 있는가
- 1.8 / 1.6 / 1.4초 기억 창의 난도가 적당한가
- 실패 공격의 원·십자 범위가 색 없이도 명확한가
- 낮은 고정 안개가 기억을 방해하지 않으면서 안개 골짜기 분위기를 유지하는가

## 8. 승인 기록

2026-09-01 사용자가 `P11 코스 승인`이라고 명시했다. 이 회색 상자와 잠금 수치를 기준으로 흑백 아트 앵커를 제작하며, 최종 컬러 에셋과 전용 오디오는 별도의 앵커 승인 전까지 만들지 않는다.
