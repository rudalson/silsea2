# P6 공용 전투·장치 시작 규칙 검토

> 상태: 사용자 승인 완료 — 2026-08-28
> 범위: 날개 방어 입력·자원, 막을 수 있는 공격, 궁수·레이저의 최초 등장 스테이지
> 제외: 최종 캐릭터·적·장치 에셋, 중간 보스, 마법 보호막·마법 벽, 토네이도

## 권장안 요약

P6의 궁수와 레이저는 **별빛 숲에서 함께 처음 소개**한다. 별빛 숲은 `x=2496`에서 날개를 지급하고 안개·쓰나미·수중 효과가 없으므로, 날개 방어를 다른 환경 규칙에 가리지 않고 학습시킬 수 있다. 기존 낭떠러지 위에는 투사체를 배치하지 않고, 안전한 지면에서 궁수와 레이저를 따로 익힌 뒤 마지막에만 조합한다.

| 결정 | 권장값 |
|---|---|
| 입력 | `Shift` 또는 `X`를 누르고 있는 동안 방어 · 게임패드 X |
| 사용 형태 | 페가수스·알리콘 |
| 자원 | 기존 비행 게이지 공유 |
| 발동 준비 | 120ms 뒤 방어 판정 시작 |
| 연속 사용 | 초당 비행 게이지 1.5초분 소모 · 0이면 자동 해제 |
| 재사용 | 해제 뒤 350ms 동안 다시 발동 불가 |
| 이동 제약 | 지상·공중 모두 수평 최고 속도 55%, 방어 중 상승 비행 불가 |
| 쉬운 모드 | 기존 `flightDrainMultiplier`를 그대로 적용해 더 오래 방어 가능 |
| 방어 범위 | 캐릭터가 바라보는 정면 150°·몸 앞 96px |
| 성공 결과 | 투사체 제거, 작은 별빛 반짝임과 전용 효과음, 플레이어 피해 없음 |

## 방어 가능한 것과 불가능한 것

투사체 데이터에 `guardable: true`가 명시된 것만 막는다. 외형이나 적 종류를 조건문으로 추측하지 않는다.

| 공격 | 날개 방어 | 이유 |
|---|---|---|
| 궁수 화살 | 가능 | P6의 기본 학습 대상 |
| 이후 추가되는 일반 투사체 | `guardable: true`일 때 가능 | 사용자가 요청한 다른 투사체 확장 지점 |
| 감자 대왕 탄환 | 기본값 불가 | 기존 보스 난이도와 패턴을 이번 단계에서 바꾸지 않음 |
| 레이저 빔 | 불가 | 투사체가 아니라 스위치·회피 장치 |
| 먹구름 번개 | 불가 | 위치 예고 뒤 피하는 공격 |
| 적 접촉·가시·낭떠러지·쓰나미 | 불가 | 날개 방어 범위 밖의 환경·접촉 피해 |

- 뒤에서 온 화살은 막지 못한다. 캐릭터가 돌아서 정면으로 받아내거나 점프로 피해야 한다.
- 같은 프레임에 여러 화살을 막아도 효과음은 최대 2회만 재생한다.
- 방어 중 점프 버튼을 함께 눌러도 상승 비행은 시작하지 않는다. 방어를 풀면 남은 게이지로 다시 비행할 수 있다.
- 알리콘도 같은 입력과 판정을 사용하지만 시간제 무적은 기존 규칙을 유지한다. 방어 성공 피드백은 표시하고 비행 게이지는 소모하지 않는다.

## 궁수 권장 규칙

| 항목 | 일반 | 쉬움 |
|---|---:|---:|
| 조준 예고 | 0.9초 | 1.25초 |
| 화살 속도 | 320px/s | 240px/s |
| 발사 뒤 빈틈 | 1.2초 | 1.55초 |
| 화면 내 동시 화살 | 최대 4개 | 최대 3개 |

- 상태는 `대기 → 조준 예고 → 1발 발사 → 빈틈` 순서다.
- 화살은 발사 순간의 플레이어 몸 중심을 향하고, 발사 뒤에는 방향을 바꾸지 않는다.
- 궁수가 화면 밖이면 조준과 발사를 멈추고 활성 화살도 화면 밖에서 즉시 회수한다.
- 궁수는 기존 적과 같이 밟기 또는 알리콘 접촉으로 처치한다. 화살 방어 성공이 궁수에게 반사 피해를 주지는 않는다.
- 조준선과 화살은 색 외에도 길쭉한 실루엣과 움직임으로 판독할 수 있어야 한다.

## 레이저·스위치 권장 규칙

| 항목 | 일반 | 쉬움 |
|---|---:|---:|
| 발사 전 예고 | 0.9초 | 1.3초 |
| 빔 유지 | 1.4초 | 1.2초 |
| 자동 휴지 | 1.2초 | 1.8초 |
| 피해 | 접촉 시 HP 1 | 동일 |

- 레이저는 `꺼짐 → 예고 → 빔 → 휴지`를 반복한다.
- 스위치는 캐릭터가 접촉하면 꺼지고, 같은 `switchId`를 가진 빔만 비활성화한다.
- 꺼진 상태는 체크포인트 부활 뒤에도 유지하지만 스테이지를 나가거나 처음부터 다시 시작하면 초기화한다.
- 스위치를 거치지 않고 예고를 보고 통과하는 경로도 유효하다. 스위치는 필수 열쇠가 아니라 위험을 줄이는 선택이다.
- 빔은 색뿐 아니라 발사기 방향, 점멸 예고선, 활성 빔의 굵기 변화로 상태를 구분한다.

## 별빛 숲 4비트 배치안

| 비트 | 위치 | 내용 | 실패 안전장치 |
|---|---:|---|---|
| 소개 | `x=2624~3136` | 날개 획득 직후, 정면에서 느린 화살 1발 | 평지·낭떠러지 없음·궁수 뒤 넓은 여유 공간 |
| 연습 | `x=3136~3712` | 궁수 1명, 방어 또는 점프로 통과 | 체크포인트와 가까움·동시 화살 1발 |
| 응용 | `x=4992~5504` | 레이저 1개와 눈앞에 보이는 스위치 | 낭떠러지 종료 뒤 넓은 지면·적 없음 |
| 조합 | `x=5504~5952` | 궁수 1명과 레이저 1개, 스위치는 선택 경로 | 구간 전 HP 회복 체크포인트·게이트 앞 안전지대 |

기존 `x=3840~4992` 낭떠러지에는 궁수·화살·레이저를 추가하지 않는다. 이동 발판과 낭떠러지 위에서 새 방어 입력까지 동시에 요구하지 않기 위해서다.
