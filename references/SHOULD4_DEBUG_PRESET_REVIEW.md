# Should S4 디버그 패널 preset 검수

> 상태: 사용자 승인 완료
> 검수일: 2026-09-03
> 승인 문구: `S4 프리셋 승인`

## 검수 주소

```text
http://localhost:4173/?visualReview=level-02&section=star_tree&offset=320&form=alicorn&easy=1&debug=1
```

포트는 개발 서버가 출력한 값에 맞춘다. 오른쪽 Graybox 패널에서 아홉 개 슬라이더 아래의 `튜닝 preset` 영역을 확인한다.

## preset 비교

| preset | 목적 | 기본값과 다른 핵심 값 |
|---|---|---|
| 이동 기본 | 승인된 현재 이동감 회귀 | 없음 |
| 초보 | 느린 최고 속도, 빠른 반응, 넓은 입력 유예 | 중력 1700, 속도 320, 공중 가속 1400, Coyote/Buffer 180ms |
| 공중 제어 검수 | 공중 방향 전환 집중 비교 | 중력 1800, 점프 -760, 공중 가속 1900, Coyote/Buffer 150ms |

전체 아홉 값은 `SHOULD_EXPANSION_PLAN.md`의 S4 표를 단일 승인 기준으로 사용한다.

## 검수 순서

1. `초보`를 선택한다. 슬라이더는 아직 기본값이고 변경 목록 아홉 개가 `현재 → 목표`로 표시되는지 확인한다.
2. `선택값 적용`을 누른다. 중력 1700, 최대 속도 320, 공중 가속도 1400 등 아홉 슬라이더가 즉시 바뀌고 버튼이 비활성화되는지 확인한다.
3. `레벨 데이터 다시 읽기`를 누른다. 재로드 성공 뒤에도 초보 선택과 아홉 값이 유지되는지 확인한다.
4. `JSON 내보내기` 후 버튼이 `복사 완료`가 되는지 확인한다. `기본값`을 누르면 승인 기본값이 복원되고 선택한 preset과의 변경 목록이 다시 나타나야 한다.
5. preset select에 초점을 두고 방향키로 항목을 바꾼 뒤 적용 버튼에서 Enter 또는 Space를 누른다. 게임 캐릭터 이동·점프 입력으로 전달되지 않아야 한다.
6. URL에서 `debug=1`을 제거해 다시 열면 Graybox 패널 자체가 생성되지 않아야 한다.
